# 김씨 생존기: 무인도

무인도에 고립된 평범한 김씨가 환경 수색물을 뒤져 필요한 것만 챙기고, 위아래로 확장한 캠프와 여러 탈출 프로젝트에 투자해 자신의 생활 방식이 반영된 코믹북 결말에 도달하는 2D 생존 게임

- 장르: 코믹 2D 횡스크롤 거점 생존·유한 자원 수색·제작·행동 기반 다중 엔딩
- 대상 플랫폼: 게임잼 Windows PC, 한국어 기본·영어 지원, 키보드·마우스와 게임패드
- 대상 플레이어: 30분 안에 섬을 뒤지고 캠프를 키우며 한 가지 탈출과 행동 기반 결말을 완주하고, 다른 경로를 다시 시도하고 싶은 싱글 플레이 이용자

## 디자인 기둥

- 다녀온 섬의 자원·장벽·위험 상태가 그대로 남는다.
- 탈출법이 다음 수색 지역과 자원 투자 우선순위를 바꾼다.
- 김씨의 동작·공간 성장·누적 생활 방식이 코믹한 결말의 근거가 된다.

## 플레이어 행동

- 이동한다
- 접근한다
- 뒤진다
- 선별한다
- 귀환한다
- 제작한다
- 연구한다
- 건설한다
- 치료한다
- 탈출을 준비한다

## 코어 루프

- 캠프를 직접 걷고 설비·생존 상태·탈출 프로젝트를 점검한다.
- 지도에서 순서대로 열린 지역의 자원 잔량·위험·단서를 비교한다.
- 지역을 이동하며 환경 수색물을 뒤지고 숨겨진 발견물을 공개한다.
- 가방과 현재 목표에 맞는 발견물만 골라 담고 귀환한다.
- 자원을 회복·도구·가방·다층 캠프·탈출 프로젝트에 투자한다.
- 조기 탈출 또는 장기 체류 판정에서 누적 행동이 반영된 코믹북 결말을 본다.

## 버티컬 슬라이스

시스템 알파를 최종 방향의 콘텐츠·아트·애니메이션·스토리·엔딩·오디오가 연결된 30분 게임잼 제출 버티컬 슬라이스로 완성한다.

플레이어 약속: 처음 10분 안에 내가 직접 섬을 뒤지고 필요한 것만 챙겨 캠프에 투자한다는 재미를 이해하고, 30분 안에 내 행동 때문에 달라진 김씨의 결말을 본다.

## 포함 범위

- 30~45초 스킵 가능한 도입과 첫 귀환·첫 제작·첫 증축·첫 탈출 프로젝트 서사 비트
- 지붕 있는 1층·2층·지하 캠프 production art와 생활·제작·탈출 설비
- 독립 레이어로 분리된 일곱 지역과 상태별 수색 오브젝트
- 김씨 idle·walk·search·facility-use·ladder·swim·hurt-sick·rest-eat 애니메이션
- 타이틀부터 엔딩 앨범까지 일관된 PC UI component set
- 일반 자원 12종·보호 부품 5종·도구 2종의 구분 가능한 아이콘
- 뗏목·연기·무전 core ending 3종과 장기 체류 2종의 실제 3컷 표현
- 코믹 2종·희귀 1종 교체 패널과 행동 modifier 4종을 목표 범위로 제작
- 환경 loop, 기능 SFX, 탈출·엔딩용 최소 음악과 sting
- KO/EN, 1280×800·1920×1080, 키보드·마우스와 게임패드

## 제외 범위

- 21개 엔딩 전부의 고유 완성 컷신
- 조명탄·고지대 중계소의 플레이 가능 완성
- 음성 더빙과 지역별 완전 고유 BGM
- 상점·전투 HUD·별도 캐릭터 시트 화면
- Steamworks 업적·클라우드·스토어 업로드
- 게임 종료 후 이어하기 세이브와 사용자 설정 run 완성

## 성공 조건

- O9에서 설명자 없이 타이틀→도입→캠프→지도→해변/숲→수색→선별→귀환→첫 투자를 10분 안에 완료한다.
- O9 첫 루프 경로에 임시 네모, 도식형 사람, contact sheet와 개발자 설명 패널이 주 표현으로 남지 않는다.
- 김씨의 발이 지면에 붙고 이동·수색·설비 사용·사다리 동작이 서로 구분된다.
- O10에서 일곱 지역이 배경·수색물·위험·주요 자원으로 즉시 구분된다.
- O10에서 뗏목·연기·무전 각 경로를 독립 seed로 25~35분 안에 완주할 수 있다.
- 필수 5개 ending이 고유 3컷로 재생되고 결과·원인·후일담과 행동 근거를 전달한다.
- 1280×800 KO/EN에서 HUD·지도·수색 트레이·캠프·엔딩이 김씨와 상호작용 대상을 과도하게 가리지 않는다.
- Release 후보에 타이틀, 설정, 조작 안내, 크레딧·라이선스, 종료와 게임잼 패키지 문서가 있다.

## 가정

- BALANCE_PROVISIONAL: O9는 30분 밸런스가 아니라 첫 5~10분 콘텐츠·프레젠테이션 가독성을 검증한다.
- 조난 원인과 도입의 구체 사건은 사용자가 방향을 고르기 전까지 확정하지 않는다.
- 게임잼에서 완성할 core ending은 뗏목·연기·무전 일반 3종과 장기 체류 2종이다.
- 코믹 2종과 희귀 1종은 core sequence의 일부 패널을 교체하는 목표 범위다.
- 기존 김씨의 생활인 실루엣은 유지하되 애니메이션용 일관된 모델 시트로 다시 정리한다.

## 아트 방향

따뜻한 열대색과 굵고 읽기 쉬운 실루엣을 사용하는 오리지널 2D 측면 일러스트. 평범하고 약간 지친 생활인 김씨의 잉크 선과 과장된 반응을 기준으로 배경 세부를 한 단계 단순화하고, PC 횡스크롤 플레이 공간을 가리지 않는 절제된 구조물·UI 문법을 사용한다. 모든 본문은 엔진 텍스트로 분리한다.

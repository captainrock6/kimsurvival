# 김씨 생존기: 무인도

무인도에 조난된 평범한 김씨가 낮에는 황당하지만 쓸모 있는 생존 설비를 만들고 직접 배치하며, 해가 지기 전 2D 횡스크롤 섬을 수색해 결국 구조 신호를 완성하는 코믹 생존 게임.

- 장르: 코믹 2D 횡스크롤 거점 생존·채집·제작 게임
- 대상 플랫폼: Windows PC / Steam, 키보드·마우스와 게임패드 지원 기반
- 대상 플레이어: 거점이 커지는 만족감, 가벼운 제작 전략, 탐험과 수집, 실패에서도 웃음을 얻는 싱글 플레이 게임을 좋아하는 Steam 이용자

## 디자인 기둥

- 평범한 김씨의 기막힌 생활력: 영웅이 아닌 보통 사람이 주운 물건으로 황당하지만 실제로 작동하는 해결책을 만든다.
- 내 손으로 달라지는 베이스캠프: 수색 결과를 새 설비와 제작법으로 바꾸고, 일반 설비를 직접 배치해 나만의 생활 공간을 만든다.
- 조금 더 챙길까, 지금 돌아갈까: 제한된 가방·체력·일몰이 매 원정의 욕심과 안전을 충돌시킨다.

## 플레이어 행동

- 이동한다
- 접근한다
- 상호작용한다
- 채집한다
- 수색한다
- 운반한다
- 제작한다
- 건설·확장한다
- 배치한다
- 연구한다
- 먹고 쉰다
- 탈출한다

## 코어 루프

- 베이스캠프 안에서 김씨를 직접 움직여 필요한 설비에 접근한다.
- 근접 안내가 뜬 설비와 상호작용해 해당 설비 전용 팝업에서 제작·건설·연구·휴식 중 필요한 준비를 한다.
- 갈 수 있는 섬 구역과 필요한 물자를 정한 뒤 제한된 가방으로 출발한다.
- 2D 횡스크롤 해변·숲·얕은 바다를 탐색하며 나무·돌·식량·표류물을 모은다.
- 체력과 남은 일광을 보며 더 수색할지 베이스캠프로 돌아갈지 결정한다.
- 귀환 물자를 생존 설비, 가방 성장, 구조 신호와 새 방 모듈 중 어디에 쓸지 선택한다.
- 직접 배치한 설비와 위·옆·지하로 확장된 캠프가 다음 준비와 원정을 바꾸며 탈출할 때까지 반복한다.

## 버티컬 슬라이스

플레이어가 한국어 또는 영어로 김씨를 직접 조작해 공간형 베이스캠프의 설비에 접근·상호작용하고, 제한적 자유 배치와 위·옆·지하 모듈 확장 중 하나 이상을 경험한 뒤 육상·수면 수색과 귀환을 반복해 20분 안에 구조 신호 완성 또는 생존 실패에 도달하도록 한다.

플레이어 약속: 수색에서 주운 하찮은 물건이 내가 직접 걸어 다니고 사용하는 설비와 복층·옆방·지하실로 변해, 김씨의 생활 공간과 다음 원정이 눈앞에서 달라진다.

## 포함 범위

- 김씨가 직접 좌우 이동하고 설비에 접근해 사용하는 측면 절개형 베이스캠프
- 범위 밖에서는 숨고 근접 시 표시되는 단일 상호작용 안내
- 상호작용 입력 뒤에만 열리고 취소하면 현장으로 돌아오는 작업대·모닥불·빗물받이·구조 신호대 전용 팝업
- 날짜·일광·허기·체력·가방 요약만 유지하는 최소 HUD
- 방 모듈 내부 일반 설비 최소 2종의 제한적 자유 배치와 무비용 재배치
- 기능 위치가 고정된 특수 설비 최소 1종의 전용 앵커 또는 구역 규칙
- 시작 방에 연결되는 위층·옆방·지하실 모듈의 유효·무효 증축 미리보기와 최소 한 번의 확정
- 모듈 출입구, 사다리 또는 계단을 통한 공간 간 이동 가능성 보존
- 준비, 주간 수색, 귀환, 일몰 정산으로 이어지는 3일 주기
- 해변·숲·얕은 바다 수색과 4칸에서 6칸으로 성장 가능한 가방 선택
- 제작·연구·건설·생존·구조 신호 완성 루프
- 한국어·영어 문자열 테이블, 언어 선택과 저장, 한국어 폴백
- 키보드·마우스와 게임패드로 핵심 루프 전체 조작

## 제외 범위

- 상점 판매, 손님 운영과 화폐 경제
- 무기, 직접 전투, 적 AI와 보스
- 복수 생존자, 동료 관계와 정착민 관리
- 여러 섬, 절차적 생성과 장기 캠페인
- 픽셀 단위 벽·바닥 그리기, 임의 크기 방, 물리 기반 구조물 적층과 구조 안정성 시뮬레이션
- 방 모듈 3종을 넘는 완성형 복층 건축과 장기 건설 기술 트리
- 복잡한 기술 트리와 수십 종의 제작법
- 낚시·농사·요리 미니게임의 완성형 구현
- 깊은 잠수, 산소 게이지, 수중 전투와 해저 던전
- 한국어·영어 이외 언어의 실제 번역과 언어별 전문 감수
- 세이브·로드, 메타 성장과 도전 과제
- Steamworks SDK, 업적, 클라우드 저장, 상점 페이지와 빌드 업로드
- 모바일·콘솔 출시와 온라인 기능
- 최종 상용 수준 아트·사운드·전체 현지화 감수

## 성공 조건

- 캠프 진입 직후 전역 행동 대시보드가 화면을 덮지 않고 김씨를 즉시 직접 이동할 수 있다.
- 설비에서 멀면 안내와 팝업이 보이지 않고, 가까이 가면 대상 하나의 안내만 나타나며, 상호작용 입력 뒤에만 해당 설비 전용 팝업이 열린다.
- 작업대 팝업에서는 제작·연구·가방 확장처럼 작업대에 속한 행동만 제공하고 다른 설비의 행동은 섞이지 않는다.
- 팝업을 취소하거나 행동을 완료하면 같은 공간의 김씨 조작으로 복귀하며 자원은 성공한 행동에서만 한 번 변경된다.
- 일반 설비 최소 2종을 모듈 내부의 서로 다른 유효 위치에 배치하고 그중 하나를 재배치한 뒤 직접 걸어가 사용할 수 있다.
- 위층·옆방·지하실 연결 후보가 유효·무효 상태를 구분하고 최소 한 모듈을 확정한 뒤 출입 경로가 막히지 않는다.
- 1280×800 ko/en에서 최소 HUD, 근접 안내와 가장 긴 설비 팝업이 공간을 과도하게 가리거나 잘리지 않는다.
- 가방이 가득 차 최소 한 번 자원을 두고 가거나 교체하는 선택이 발생한다.
- 제작·연구·가방 확장 또는 방 확장 하나가 다음 원정의 선택을 분명하게 바꾼다.
- 한국어와 영어 각각으로 시작부터 성공 또는 실패 결말까지 핵심 루프를 완료할 수 있다.
- 키보드·마우스와 게임패드 어느 쪽으로도 접근, 상호작용, 팝업 선택·취소와 배치 모드를 완료할 수 있다.
- 해안에서 수영 상태로 전환해 수상 지점을 수색하고 다시 육지로 돌아올 수 있다.

## 가정

- 승인된 방향 목업 `Docs/Design/References/approved-spatial-base-camp-concept.png`은 공간과 상호작용 흐름의 기준이며 최종 아트는 아니다.
- 김씨는 초능력이나 전문 생존 기술이 없는 평범한 성인이며 관찰력과 생활 잔기술로 문제를 해결한다.
- 설비 전용 팝업이 열린 동안 일반 이동은 잠기고 확인 또는 취소 후 현장 플레이로 복귀한다.
- 근접 후보가 겹치면 가장 가까우며 바라보는 방향에 있는 설비 하나만 활성 대상으로 선택한다.
- 모듈 사이 이동은 출입구와 사다리 또는 계단 같은 명시적 연결부를 사용한다.
- 첫 수직 슬라이스는 한국어와 영어로 핵심 루프 전체를 플레이할 수 있게 한다.
- 번역이 누락된 키는 한국어를 표시하고 개발 빌드에서 누락 사실을 기록한다.
- 설치 후 재배치는 별도 자원 소모 없이 배치 모드에서 지원한다.

## 아트 방향

밝고 따뜻한 열대색을 기반으로 한 오리지널 2D 측면 일러스트. 굵고 읽기 쉬운 형태, 과장된 포즈, 손으로 급조한 듯 비뚤지만 기능적인 설비를 사용한다. 김씨의 표정과 도구의 예상 밖 반응에서 코미디가 발생하되 생존 상태, 배치 가능 영역과 상호작용 지점은 즉시 읽혀야 한다. UI와 아트에 언어별 본문을 굽지 않고 엔진 텍스트를 사용한다. 특정 게임·영화의 캐릭터, 로고, 고유 아이콘, 문구, 정확한 화면 구성이나 스타일은 복제하지 않는다.

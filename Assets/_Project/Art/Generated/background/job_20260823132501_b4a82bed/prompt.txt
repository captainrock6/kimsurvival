# 김씨 생존기: 무인도

무인도에 조난된 평범한 김씨가 낮에는 황당하지만 쓸모 있는 생존 설비를 만들고 직접 배치하며, 해가 지기 전 2D 횡스크롤 섬을 수색해 결국 구조 신호를 완성하는 코믹 생존 게임.

- 장르: 코믹 2D 횡스크롤 거점 생존·채집·제작 게임
- 대상 플랫폼: Windows PC / Steam, 키보드·마우스와 게임패드 지원 기반
- 대상 플레이어: 거점이 커지는 만족감, 가벼운 제작 전략, 탐험과 수집, 실패에서도 웃음을 얻는 싱글 플레이 게임을 좋아하는 Steam 이용자

## 디자인 기둥

- 평범한 김씨의 기막힌 생활력: 영웅이 아닌 보통 사람이 주운 물건으로 황당하지만 실제로 작동하는 해결책을 만든다.
- 내 손으로 달라지는 베이스캠프: 수색 결과를 새 설비와 제작법으로 바꾸고, 일반 설비를 직접 배치해 나만의 생활 공간을 만든다.
- 조금 더 챙길까, 지금 돌아갈까: 제한된 가방·체력·일몰이 매 원정의 욕심과 안전을 충돌시킨다.

## 플레이어 행동

- 이동한다
- 접근한다
- 상호작용한다
- 채집한다
- 수색한다
- 운반한다
- 제작한다
- 건설·확장한다
- 배치한다
- 연구한다
- 먹고 쉰다
- 탈출한다

## 코어 루프

- 베이스캠프 안에서 김씨를 직접 움직여 필요한 설비에 접근한다.
- 근접 안내가 뜬 설비와 상호작용해 해당 설비 전용 팝업에서 제작·건설·연구·휴식 중 필요한 준비를 한다.
- 갈 수 있는 섬 구역과 필요한 물자를 정한 뒤 제한된 가방으로 출발한다.
- 2D 횡스크롤 해변·숲·얕은 바다를 탐색하며 나무·돌·식량·표류물을 모은다.
- 체력과 남은 일광을 보며 더 수색할지 베이스캠프로 돌아갈지 결정한다.
- 귀환 물자를 생존 설비, 가방 성장, 구조 신호와 새 방 모듈 중 어디에 쓸지 선택한다.
- 직접 배치한 설비와 위·옆·지하로 확장된 캠프가 다음 준비와 원정을 바꾸며 탈출할 때까지 반복한다.

## 버티컬 슬라이스

플레이어가 한국어 또는 영어로 김씨를 직접 조작해 공간형 베이스캠프의 설비에 접근·상호작용하고, 제한적 자유 배치와 위·옆·지하 모듈 확장 중 하나 이상을 경험한 뒤 육상·수면 수색과 귀환을 반복해 20분 안에 구조 신호 완성 또는 생존 실패에 도달하도록 한다.

플레이어 약속: 수색에서 주운 하찮은 물건이 내가 직접 걸어 다니고 사용하는 설비와 복층·옆방·지하실로 변해, 김씨의 생활 공간과 다음 원정이 눈앞에서 달라진다.

- 범위 밖에서는 숨고 근접 시 내레이션 카드 아래 중앙 상단에 표시되는 `ui.camp-contextual-interaction.compact-a` 단일 한 줄 상호작용 안내

## 성공 조건

- 캠프 진입 직후 전역 행동 대시보드가 화면을 덮지 않고 김씨를 즉시 직접 이동할 수 있다.
- 설비에서 멀면 안내와 팝업이 보이지 않고, 가까이 가면 내레이션 카드 아래 중앙 상단에 대상 하나의 한 줄 안내만 나타나며, 상호작용 입력 뒤에만 해당 설비 전용 팝업이 열린다.
- 작업대 팝업에서는 제작·연구·가방 확장처럼 작업대에 속한 행동만 제공하고 다른 설비의 행동은 섞이지 않는다.
- 팝업을 취소하거나 행동을 완료하면 같은 공간의 김씨 조작으로 복귀하며 자원은 성공한 행동에서만 한 번 변경된다.
- 일반 설비 최소 2종을 모듈 내부의 서로 다른 유효 위치에 배치하고 그중 하나를 재배치한 뒤 직접 걸어가 사용할 수 있다.
- 위층·옆방·지하실 연결 후보가 유효·무효·LOCKED·SHORT·READY를 구분하고 작업대 뒤 W2/D1을 한 번 차감해 한 모듈을 확정한 뒤 출입 경로가 막히지 않는다.
- 첫 사용자가 전역 메뉴 없이 연결 슬롯에 직접 접근해 50초 안에 preview를 열고 75초 안에 위·옆·지하 세 후보를 본 뒤 90초 안에 작업대 잠금과 W2/D1을 이해한다.
- 연결 없음·겹침·지형·필수 통로의 geometry와 작업대 잠금·자원 부족·이미 1회 확정의 economy가 canonical reason ID로 분리되고 keyboard/gamepad가 같은 상태 전이를 낸다.
- 가방 4칸 숙련 경로는 Day 3~4, 4→6칸 첫 플레이 목표 경로는 방 하나를 포함해 Day 4~5 구조에 도달하고 과수색 탈진과 Day 5 기한 실패도 재현 가능하다.
- Day 3·4 정산은 기한 실패를 내지 않고 Day 5 정산 미완성만 기한 실패이며, 구조 신호 2단계는 어느 날이든 즉시 구조 성공한다.
- 1280×800 ko/en/qps-long에서 compact-a가 x=640, 내레이션 아래 12px, locale별 300/380/520×64px 이내 한 줄을 지키고 TopHUD·BottomHelp·김씨·활성 설비·보행 통로와 겹치거나 잘리지 않는다.
- 가방이 가득 차 최소 한 번 자원을 두고 가거나 교체하는 선택이 발생한다.
- 제작·연구·가방 확장 또는 방 확장 하나가 다음 원정의 선택을 분명하게 바꾼다.
- 한국어와 영어 각각으로 시작부터 성공 또는 실패 결말까지 핵심 루프를 완료할 수 있다.
- 키보드·마우스와 게임패드 어느 쪽으로도 접근, 상호작용, 팝업 선택·취소와 배치 모드를 완료할 수 있다.

- 근접 후보가 겹치면 가장 가까우며 바라보는 방향에 있는 설비 하나만 활성 대상으로 선택한다.
- Day 1~2 생존 기반·도구, Day 3 성장 선택, Day 4~5 구조 완성은 권장 곡선이지 날짜별 강제 순서가 아니다.
- 5일 1차 재기준선은 기존 밸런스 v0.2의 비용·획득량·가방·허기·체력·일광·회복값을 모두 동결한다.
- 근접 안내는 compact-a를 채택하지만 Wave 11 연결 슬롯 표식 세 후보는 미선택 review-only다.
- 새 게임 시작 D0에서는 작업대를 90초 안에 자연 건설할 수 없으므로 첫 발견은 연결 슬롯 접근→세 후보 preview→작업대 잠금·W2/D1 이해까지이며 실제 확정은 자연 원정 뒤 같은 슬롯에서 한다.
- 모듈 사이 이동은 출입구와 사다리 또는 계단 같은 명시적 연결부를 사용한다.
- 첫 수직 슬라이스는 한국어와 영어로 핵심 루프 전체를 플레이할 수 있게 한다.
- 번역이 누락된 키는 한국어를 표시하고 개발 빌드에서 누락 사실을 기록한다.
- 설치 후 재배치는 별도 자원 소모 없이 배치 모드에서 지원한다.

## 아트 방향

밝고 따뜻한 열대색을 기반으로 한 오리지널 2D 측면 일러스트. 굵고 읽기 쉬운 형태, 과장된 포즈, 손으로 급조한 듯 비뚤지만 기능적인 설비를 사용한다. 김씨의 표정과 도구의 예상 밖 반응에서 코미디가 발생하되 생존 상태, 배치 가능 영역과 상호작용 지점은 즉시 읽혀야 한다. UI와 아트에 언어별 본문을 굽지 않고 엔진 텍스트를 사용한다. 특정 게임·영화의 캐릭터, 로고, 고유 아이콘, 문구, 정확한 화면 구성이나 스타일은 복제하지 않는다.

| 후보 ID | 장점 | 우려 |

## 감사 결론

- 기존 Forge 원화는 좌측 얕은 바다 → 중앙 해변·바위턱 → 우측 숲 입구가 한 화면에 명확하다.
- 중앙 모래 지면에서 김씨의 주황·초록 비율과 네 자원 아이콘은 1280×800에서 읽힌다.
- 수영 전환은 해안 경사로 읽히며 C안이 가장 넓게 보여준다.
- 우측 숲은 장벽과 색·질감이 비슷하다. A안은 장벽 실루엣이 가장 쉽게 묻힌다.
- 현재 런타임 캡처는 단색 프로토타입 배경이다. 탐색·수영·장벽 상태 전이는 보여주지만 최종 배경 합성 품질을 증명하지 않는다.
- 원화 우측에는 쓰러진 통나무와 덩굴이 이미 구워져 있다. 이 상태로 채택된 독립 `blocked/interactable/cleared` 장벽을 올리면 장벽이 두 개처럼 보이고 cleared 뒤에도 길이 막힌 그림이 남는다.

## 선택 이후에만 적용할 레이어 규격

공통 캔버스는 1672×941, 공통 원점은 bottom-center `(0.5,0.0)`이다.

1. `coastForest.far.skySeaIslands` — 불투명 원경.
2. `coastForest.mid.forestRocks` — 투명 중경. 장벽이 놓일 숲 입구에는 구워진 통나무를 남기지 않는다.
3. `coastForest.ground.playableShore` — 해안 경사·모래·바위 지면. 충돌은 별도 엔진 데이터다.
4. `coastForest.objects.resourceNodes` — 독립 true-alpha, bottom-center 접점 피벗.
5. `coastForest.objects.vineWoodBarrier` — 기존 채택된 3상태 true-alpha 자산.
6. `coastForest.player.mrKim` — 배경 grading의 영향을 받지 않는다.
7. `coastForest.foreground.edgeFoliage` — 화면 가장자리만 덮고 발·수영 경계를 가리지 않는다.
8. HUD·내레이션·compact prompt·가방·하단 도움말은 모두 별도 UI 레이어다.

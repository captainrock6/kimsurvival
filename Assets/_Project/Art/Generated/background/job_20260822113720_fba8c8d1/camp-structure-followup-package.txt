김씨 생존기: 무인도 - 베이스캠프 후속 설비 파츠 패키징 규격

대상 안정 자산 ID: object.camp-structures
배경 기준 자산 ID: background.island-camp

1. 산출물 구성
- 모닥불, 작업대, 빗물받이, 구조 신호대를 각각 독립 PNG로 제공한다.
- 일반 설비는 주변 지면, 고정 슬롯, 배치 표시, 접촉 그림자를 포함하지 않는 실제 투명 배경으로 제작한다.
- 구조 신호대는 배경 외곽의 전용 자연 지형 앵커에 맞는 별도 특수 설비로 취급한다.
- 배치 유령, 유효, 무효 이미지를 별도 래스터로 굽지 않고 Unity 틴트 또는 선택적 단색 마스크로 표현한다.

2. 공통 정렬 규칙
- 모든 설비의 피벗은 바닥 접점 기준 하단 중앙(bottom-center)으로 통일한다.
- 동일한 100 PPU 기준과 동일한 측면 카메라 원근, 광원 방향, 외곽선 굵기를 사용한다.
- 파츠 캔버스에는 최소 8%의 투명 안전 여백을 두고 시각 요소가 가장자리에 닿지 않게 한다.
- 캐릭터 접근 방향을 가리지 않는 좌우 상호작용 여백을 확보한다.

3. 배치 발자국 메타데이터
- 각 설비마다 footprintWidth, footprintHeight, interactionRadius, blocksTraversal, anchorType을 기록한다.
- 일반 설비 anchorType은 free-grid, 구조 신호대 anchorType은 signal-fixed로 지정한다.
- 발자국은 시각적 장식이 아니라 Unity 배치 검사와 충돌 판정용 데이터로 유지한다.

4. Unity 임포트 기준
- Texture Type: Sprite (2D and UI), Sprite Mode: Single, Filter: Bilinear, Compression: Normal Quality.
- Alpha Is Transparency를 활성화하고 밉맵은 실제 카메라 축소 테스트 후 결정한다.
- 배치 상태 틴트에도 알파 가장자리와 내부 명암이 유지되는지 확인한다.

5. 품질 확인
- 1280x800에서 김씨와 함께 놓았을 때 크기, 바닥 접점, 상호작용 여백이 일관되어야 한다.
- 서로 다른 유효 위치에 배치해도 배경 광원과 지면에 자연스럽게 맞아야 한다.
- 유효/무효 틴트, 게임패드 포커스, 겹침·경계·필수 이동 통로 검사가 명확해야 한다.
- 글자, 숫자, 아이콘, 로고, 고정 위치 표식을 파츠에 굽지 않는다.

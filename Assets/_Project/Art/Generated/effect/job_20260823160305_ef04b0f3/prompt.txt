# 김씨 생존기: 무인도

무인도에 조난된 평범한 김씨가 50일의 기한 동안 위험을 견디고 수집 지역을 골라 물자를 모으며, 다섯 가지 이상의 탈출 계획과 자신이 살아온 방식에 따라 정상적이거나 황당한 결말을 맞는 코믹 2D 거점 생존 게임.

- 장르: 코믹 2D 횡스크롤 거점 생존·지역 선택 수색·제작·다중 엔딩 게임
- 대상 플랫폼: Windows PC / Steam, 키보드·마우스와 게임패드 지원 기반
- 대상 플레이어: 거점 성장, 수색 계획, 생존 변수, 여러 해결법과 수집형 엔딩을 즐기며 한 판의 행동이 결말로 돌아오는 싱글 플레이 게임을 좋아하는 Steam 이용자

## 디자인 기둥

- 김씨가 살아온 방식이 결말이 된다: 탈출법, 누적 행동과 특별 사건이 정상·병맛·희귀 엔딩을 결정한다.
- 오늘 어디로 갈지와 무엇을 감수할지 고른다: 지역별 자원 전망과 위험을 보고 장비·가방·귀환 시점을 결정한다.
- 캠프는 메뉴가 아니라 생활 공간이다: 직접 이동·상호작용하고 설비를 배치·증축해 위험에 대비하고 여러 탈출 계획을 진전시킨다.

## 플레이어 행동

- 이동한다
- 접근한다
- 상호작용한다
- 지역을 선택한다
- 준비한다
- 수색한다
- 채집한다
- 수영한다
- 운반한다
- 제작한다
- 건설·확장한다
- 연구한다

## 코어 루프

- 베이스캠프에서 김씨를 직접 움직여 설비에 접근하고 허기·체력·부상·질병·캠프 피해를 확인한다.
- 작업대, 모닥불, 저장고, 치료·연구 설비와 상호작용해 오늘의 장비와 장기 탈출 계획을 준비한다.
- 캠프 출구 또는 지도 오브젝트와 상호작용해 수집 지도를 열고 지역별 예상 자원, 위험, 이동 시간, 날씨, 필요 장비와 특별 발견 가능성을 비교한다.
- 선택한 2D 횡스크롤 지역에서 제한된 가방·체력·일광을 관리하며 수색하고 예고된 위험과 돌발 사건에 대응한다.
- 더 챙길지 귀환할지 판단하고, 일몰 또는 자발적 귀환 뒤 물자·부상·사건 결과를 캠프로 가져온다.
- 귀환 물자를 생존, 치료, 캠프 보강, 가방·공간 성장과 다섯 가지 이상의 탈출 계획 중 어디에 쓸지 선택한다.
- 하루를 정산해 위험과 세계 상태를 갱신하고, Day 50 이전 탈출 또는 Day 50 종료까지 반복한다.
- 탈출 방법 또는 Day 50 상태, 누적 생활 방식과 특별 사건을 조합해 고유 엔딩과 코믹북 컷신을 해금한다.

## 버티컬 슬라이스

실제 기본 데드라인이 Day 50인 빌드에서 김씨가 캠프 지도 오브젝트를 직접 사용해 서로 다른 세 수집 지역 중 하나를 고르고, 표시된 자원·위험 정보에 맞춰 준비·수색·귀환한 뒤 예고 가능한 위험 하나를 완화하고 서로 다른 두 탈출 프로젝트 중 하나를 진전시키며, 행동 통계가 엔딩 판정 입력으로 누적되는 30분 이내의 대표 루프를 검증한다.

플레이어 약속: 오늘 고른 지역과 감수한 위험, 캠프에 투자한 설비와 탈출 계획이 50일 뒤의 김씨와 엔딩을 바꾼다.

## 성공 조건

- 새 표준 run은 Day 1/50으로 시작하고 Day 49 미탈출 정산은 계속되며 Day 50 정산 또는 조기 탈출에서만 terminal ending resolution이 실행된다.
- 지도 오브젝트에서 멀면 지역 선택 UI가 숨고 가까이서 상호작용한 뒤에만 열리며 취소하면 같은 캠프의 김씨 조작으로 복귀한다.

- 플레이어가 위험을 사전에 확인하고 장비·설비·지역 변경 중 하나로 피해를 줄일 수 있으며 대부분의 위험은 원인 없이 즉사시키지 않는다.
- 부상은 미처치 시 악화되고 치료 시 회복되며, 캠프 침입·도난은 저장고 보강 또는 방어 수단으로 완화되고 자원 변화가 한 번만 적용된다.
- escape.raft/smoke/radio/flare/beacon 다섯 method가 지역·연구·설비·핵심 부품·준비 기간·위험 중 최소 두 축 이상 다르고, 연기·무전 두 대표 경로는 플레이 가능한 smoke data로 조기 탈출할 수 있다.
- 시작 3개와 확장 3개의 region profile이 자원 풍부함·위험·날씨·장비·이동 시간·특별 발견과 핵심 부품의 primary·alternative·pity를 모두 가진다.
- 배고픔·질병·부상·자연재해·야생동물·식량 도난·캠프 피해의 7개 hazard가 예고→발생→완화→회복, 일일 예산과 원자 transaction을 가진다.
- 엔딩 판정은 탈출 방법 또는 Day 50 상태, run 전체의 우세 행동 점수, 특별 사건을 순서대로 사용하고 마지막 행동 하나로 우세 생활 방식이 뒤집히지 않는다.
- 19개 ending이 안정 ID, ko/en 제목·요약, 3개 core panel beat, modifier panel, 갤러리 힌트와 future-only achievement mapping ID를 가지며 4개 sample ending만 먼저 실행한다.

- 기존 캠프 근접 안내, 배치, 모듈, 가방, 구조 신호, 수영과 qps-long 10/10 GREEN 계약이 회귀하지 않는다.

## 가정

- Day 50에 탈출하지 못해도 단일 deadline 문구로 끝내지 않고 그동안의 우세 행동과 특별 사건에 따라 정착·자연인·기술 지배 등 서로 다른 엔딩을 판정한다.
- 표준 run은 다섯 탈출법 전체를 데이터로 제공하되 seed와 플레이 선택에 따라 난도가 달라지며 최소 세 경로는 진행 불가능 상태 없이 완성 가능하도록 보장한다.
- 수집 지도는 상시 전역 대시보드가 아니라 출발 준비 중에만 열리고 닫으면 같은 캠프 공간으로 돌아오는 설비형 팝업이다.
- 지역의 자원 표시는 풍부·보통·희귀·미확인 같은 범주를 사용하고 정확한 수량과 사건 결과는 공개하지 않는다.
- 야생동물 대응은 본격 액션 전투보다 회피, 장비, 위협, 함정과 캠프 방어를 우선한다.
- 위험 강도는 50일 동안 단조롭게 상승하지 않고 세계 상태와 플레이 행동에 따라 변하며 감당 불가능한 중첩을 막는 일일 위험 예산과 회복 가능한 평온일을 둔다.
- 엔딩 컷신은 3~5장 코믹북 패널을 기본으로 하고 희귀 대표 엔딩만 추가 애니메이션을 받을 수 있다.
- 게임 내 엔딩 갤러리는 실루엣과 비스포일러 힌트를 제공하며, 사용자 설정 run의 업적 인정 정책은 Steam 연동 단계에서 별도로 결정한다.
- 현재 5일 빌드와 Wave 12~14 자연 경로 문서는 새 구조의 구현 증거가 아니라 기존 캠프·수색·UI·원자성 회귀 기준으로만 보존한다.
- 사용자 설정 플레이에서는 추후 데드라인, 생존 소모, 위험 빈도와 자원 희귀도를 조절할 수 있지만 첫 구현은 표준 Day 50 규칙을 우선한다.
- Wave 15 콘텐츠 매트릭스의 준비 일수, 위험 예산, pity 횟수와 행동 점수 임계값은 구현 smoke용 SAMPLE_ONLY이며 사용자 플레이테스트 전 정식 50일 밸런스로 잠그지 않는다.

## 아트 방향

밝고 따뜻한 열대색을 기반으로 한 오리지널 2D 측면 일러스트. 굵고 읽기 쉬운 형태, 과장된 포즈와 표정, 표류물로 급조한 설비를 사용한다. 수집 지도는 원화풍 무인도 지도와 명료한 노드·아이콘·정보 카드를 결합하되 특정 게임의 정확한 화면 구성을 복제하지 않는다. 위험은 잔혹함보다 상황과 결과가 읽히는 코믹한 실루엣·상태 아이콘으로 표현한다. 엔딩은 3~5장 코믹북 패널과 짧은 전환 효과를 기본으로 하며 모든 본문은 엔진 텍스트로 분리한다.

### 핵심 부품 보호와 pity

- seed 생성 뒤 다섯 부품의 primary·alternative 배치를 검사해 최소 세 탈출 method가 완성 가능한지 확인한다. 실패하면 일반 자원이 아니라 핵심 부품 배치만 재추첨하고 이유를 기록한다.
- 획득한 핵심 부품은 보호 project inventory로 이동한다. 식량 도난과 일반 캠프 피해는 삭제할 수 없다. 특별 위험은 `damaged`로 바꿀 수 있지만 결정론적 수리 경로를 함께 제공해야 한다.
- 동일 부품 중복은 다른 미발견 부품의 pity를 초기화하지 않는다.
- `SAMPLE_ONLY`: 미보유 상태에서 primary 또는 alternative 지역의 완료 수색 3회면 대체 출처 힌트를 공개하고 가중치를 올린다. 5회면 다음 eligible 결과의 optional loot보다 먼저 해당 부품을 보장한다.

### 중첩 예산과 원자성

- `SAMPLE_ONLY`: 일일 예산 4, minor/moderate/major 가중치 1/2/3, 새 major 최대 1, 동시 active 최대 2.
- critical hunger는 랜덤 roll이 아니지만 active 한 칸을 예약한다. major 재해(3)와 moderate 부상(2)은 같은 날 새로 발생할 수 없다.
- 한 침입에서 도난과 파손이 함께 보이면 하나의 `hazardInstanceId`가 예산과 손실을 소유한다. 두 개의 독립 차감을 만들지 않는다.
- major 결과 다음 날은 회복에 예산 2 이상을 예약하며 같은 family의 새 major를 금지한다.
- preview·cancel은 무변경이다. `resolve`는 상태·자원·행동 점수·로그를 idempotency key 하나로 원자 적용하고, retry·locale·입력 장치 전환으로 재적용되지 않는다.

## 4. 행동 점수와 엔딩 판정

안정 통계 ID는 `stat.swimming`, `stat.farming`, `stat.hunting-trapping`, `stat.mechanics`, `stat.building`, `stat.search`, `stat.hazard-response`다. 입력 횟수나 이동 시간을 그대로 세지 않고 완료된 의미 행동만 센다.

`SAMPLE_ONLY` 점수 계약:

- 의미 행동 1회는 1~2점, 통계별 하루 최대 4점이다.
- 첫 우세 후보는 누적 12점 이상이며 2위보다 4점 앞서야 한다.
- 이미 정해진 우세 생활 방식을 바꾸려면 새 후보가 6점 앞서야 한다. 단일 행동 최대 2점이므로 마지막 행동 하나로 뒤집을 수 없다.
- 탈출 프로젝트의 마지막 완료 버튼은 생활 방식 점수를 추가하지 않는다.

판정 순서:

1. terminal은 `escape_complete`가 `day50_settlement`보다 우선한다.
2. ending 후보는 `rare → comic → normal → Day50 lifestyle → Day50 fallback` 순이다.
3. 같은 단계 후보는 `priority 내림차순 → 충족 조건 수 내림차순 → 특별 사건 최초 day 오름차순 → ending ID ASCII 오름차순`으로 하나만 고른다.
4. core ending 뒤 우세 행동 modifier 최대 1장과 사건 scar modifier 최대 1장을 삽입할 수 있다. modifier는 `endingId`를 바꾸지 않는다.

4. 같은 seed fixture와 ending snapshot을 전후 재실행한다.

## 7. 구현·QA 수용 조건

- catalog count는 method 5, region 6, hazard 7, ending 19, modifier 9이다. ID는 중복되지 않고 모든 참조가 존재한다.
- 같은 seed는 같은 key-part 배치와 hazard 선택을 만든다. seed 검증은 최소 세 탈출법의 primary+alternative chain을 보장한다.
- 위험 preview/cancel은 무변경이며 resolve/recovery는 서로 다른 idempotent transaction이다.
- 같은 ending snapshot은 항상 같은 `endingId`, 판정 근거, panel sequence와 achievement mapping ID를 반환한다.
- 정상 탈출 fallback 5개와 Day50 fallback `ending.stay.just-kim` 때문에 유효 terminal snapshot이 미판정으로 끝나지 않는다.
- ko/en 제목·요약·힌트와 panel key가 모두 존재하고 qps-long은 레이아웃 QA 전용이다.
- 물리 게임패드, 실제 사용자 50일 run, 최종 밸런스와 Steamworks는 실행 증거 없이는 PASS로 기록하지 않는다.

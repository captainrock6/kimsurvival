## 세 탈출 경로 유한 자원 감사

대표 seed `15000501`, `170017`, `180018`, `220026`, `420042`에서 다음을 모두 만족했다.

- 뗏목: 일반 자원 14단위와 보호된 돛천으로 완료 가능
- 대형 연기 신호: 일반 자원 22단위와 보호된 부싯돌로 완료 가능
- 무전 구조 신호: 일반 자원 12단위와 서로 다른 지역의 전자 부품 3개로 완료 가능
- 각 seed는 세 경로 전부 `naturally completable`, `no softlock`이며 중복 비용 지불이 없다.

## 사다리·카메라 계약

- 사다리 범위에서 `W/S`, `↑/↓`, 게임패드 세로 축을 유지하면 김씨가 직접 등반·하강한다.
- 등반 중에는 X 좌표가 고정되고 입력을 놓으면 멈춘다.
- 종착점에서 정확한 층과 `StableRoomId`가 확정된다.
- 월드 카메라만 김씨를 부드럽게 따라 상하 이동하며 HUD는 화면에 고정된다.
- 작업대 같은 근처 설비 상호작용은 사다리보다 우선한다.

## O4 사용자 재테스트 체크리스트

1. 캠프에서 뗏목·대형 연기 신호·무전 구조 신호 세 이름표를 모두 발견한다.
2. 각 팝업에서 현재 진행, 다음 단계, 보유/필요 재료와 핵심 부품을 설명 없이 읽는다.
3. 수색 자원만으로 선택한 탈출 경로 하나를 완료한다.
4. 2층과 지하실을 사다리로 오르내리고, 카메라와 HUD 동작을 확인한다.
5. 작업대 위에서 작업대 사용이 사다리나 증축 안내보다 우선하는지 확인한다.
6. 가능하면 물리 게임패드로 같은 흐름을 수행한다.

최종 판정은 사용자 O4 수기 테스트가 끝날 때까지 `OWNER_RETEST_PENDING`이다.

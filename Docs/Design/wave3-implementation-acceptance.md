## 1. Wave 3 승인 결정

1. Wave 3의 런타임 목표는 현행 수치가 아니라 `밸런스 v0.2`다. 시작 식량 `0`, 시작 허기 `70`, 하루 허기 소모 `35`를 적용하고 나머지 노드·가방·비용·이동 소모는 우선 동결한다.
2. 본선 승인 경로는 3일차에 작업대→밧줄→확장 수색→돌도끼·모닥불→구조 신호 2단계를 거치는 3회 원정이다. 2회 원정 구조는 숙련 최소 경로로 허용하되 전체 기능 검증을 대신하지 않는다.
3. 성공만 증명하지 않는다. 일몰 강제 귀환은 비종료 상태, 체력 0은 즉시 탈진 실패, 3일차 정산 시 신호 2단계 미완성은 기한 실패로 서로 다르게 판정되어야 한다.
4. 일반 설비는 제한적 자유 배치와 무비용 재배치를 유지하되, 기능은 김씨가 1.25 unit 안으로 접근해야만 사용한다. 구조 신호대는 단일 전용 앵커에서만 진행한다.
5. `qps-long`은 세 번째 비출하 QA 로케일이다. 전체 canonical 138개 키를 35~50% 확장해 레이아웃·폰트·입력 프롬프트·데이터 기반 로케일 등록을 검증한다. 실제 `es`, `ja`, `zh-Hans`, `zh-Hant` 번역은 만들지 않는다.
6. `c1b18a6`의 P1 월드 라벨과 P2 제3 로케일 확장성은 다음 구현 대상으로 승인한다. 배치 가독성과 물리 게임패드는 코드를 먼저 바꾸지 않고 독립 QA를 선행한다. Steamworks·App ID·Depot·스토어·업로드는 수직 슬라이스 이후다.

## 5. 제3 로케일과 후속 JA/ZH/ES 수용 기준

### 5.1 로케일 역할

| ID | 역할 | 출하 | 필수 계약 |
|---|---|---:|---|
| `ko` | 의미·코미디 톤 기준 원문, 최종 폴백 | 예 | canonical 138/138, 누락 0 |
| `en` | 첫 지원 언어 | 예 | 138/138, placeholder·상태 의미가 ko와 동일 |
| `qps-long` | 장문·확장 글리프·데이터 등록 QA | 아니요 | en 기반 35~50% 결정적 확장, `⟦…⟧`, 토큰·숫자·태그 보존 |
| `es`, `ja`, `zh-Hans`, `zh-Hant` | 후속 실제 번역 대상 | 아직 아니요 | 같은 138키와 메타데이터를 추가할 때 게임 플레이 코드 변경 0 |

### 5.2 구조 승인 조건

- 등록 로케일 목록을 데이터에서 읽는다. `ko↔en` 이진 분기나 locale별 화면 코드를 금지하며, `qps-long` 추가 diff에 게임 규칙·화면 분기 수정이 없어야 한다.
- canonical 138개 키는 locale별로 같은 ID를 쓴다. locale 접미사 키, 위치 인수 `{0}`·`{1}`, 한국어 조사 결합을 새로 만들지 않는다.
- `qps-long`은 모든 138키를 생성한다. 키 누락·미번역·고아·중복은 0이고 named placeholder 이름·자료형·개수는 ko/en과 100% 일치한다.
- 의도적 개발 전용 누락 probe는 canonical 밖에 둔다. 누락 시 같은 키의 ko가 표시되고 빈칸·키 문자열·예외 없이 `requestedLocale`, `fallbackLocale`, `key`, `context`를 개발 로그에 인스턴스당 1회 남긴다.
- `qps-long`은 제품의 일반 언어 선택 목록과 제품 빌드에서 숨기고 QA 플래그나 개발 설정으로만 선택한다.

### 5.3 텍스트 팽창·폰트·입력

- 1280×800에서 `qps-long`의 캠프, HUD, 배치, 수색·수영, 가방 교체, 설정, 성공·실패 화면을 모두 캡처한다.
- 잘림·겹침·화면 밖 배치·의미를 숨기는 말줄임표·포커스 침범·tofu는 각 0건이다. 본문·보조문구는 18px, 버튼·핵심 수치는 20px 미만으로 축소하지 않는다.
- 폰트 폴백은 locale 메타데이터의 `주 폰트→공용 숫자·기호 폰트` 순서로 결정하며 OS의 임의 폰트에 의존하지 않는다. 향후 ja, zh-Hans, zh-Hant는 서로의 CJK 폰트를 무조건 대체재로 쓰지 않고 locale별 승인 폰트와 라이선스를 연결한다.
- qps-long 생성기는 `á é í ó ú ü ñ ¿ ¡`를 포함한다. 별도 개발용 글리프 probe에서 `Español`, `日本語`, `简体中文`, `繁體中文`, 숫자와 공통 문장부호를 각 로케일 폰트 체인으로 렌더해 누락 0을 확인한다. 실제 번역 승인으로 간주하지 않는다.
- 입력 문구는 `{device}`, `{move}`, `{confirm}`, `{cancel}`, `{language}` 같은 action placeholder를 사용한다. `A/D`, `Space`, `F1`, `A/B/X/Y`를 번역 본문에 고정하지 않는다.
- 키보드·마우스↔게임패드 전환 시 현재 locale과 게임 상태는 유지되고 입력 프롬프트만 같은 프레임 또는 허용된 비동기 완료 뒤 갱신된다.

### 5.4 저장 데이터의 언어 비의존성

- 플레이어용 세이브·로드 화면과 장기 저장 기능은 계속 수직 슬라이스 밖이다. Wave 3는 현재 locale 설정 저장과 QA용 정규화 진행 snapshot으로 직렬화 계약만 검증하며 새 저장 UX를 추가하지 않는다.
- 진행 상태가 직렬화되는 현재 QA snapshot과 향후 제품 저장에는 `day`, W/S/F/D 수량, E/H/L, stable item·tech·structure ID, 설비 좌표, 신호 단계와 결과 enum만 쓴다. 번역 문자열, 표시명, locale별 table entry ID를 넣지 않는다.
- locale 환경설정은 진행 snapshot과 별도 키로 관리한다. 언어 전환·잘못된 locale 복구·qps-long 제거가 진행 상태를 변경하거나 snapshot을 무효화하면 P1이다.
- 같은 QA snapshot을 ko에서 만들고 en과 qps-long에서 복원한 뒤 다시 ko로 돌아와 Day, 자원, 연구·도구, 설비 위치, 신호 단계, 결과가 byte-for-byte 또는 정규화 구조 비교로 같아야 한다.
- 미지원 locale 값은 ko로 폴백하고 1회 경고를 남기되 원래 진행 snapshot은 다시 쓰거나 삭제하지 않는다.

## 7. 증거 계약과 최종 Go/No-Go

Wave 3 구현은 `Artifacts/Wave3/<run-id>/` 아래에 다음을 새 실행으로 남긴다. e695 또는 기존 `Artifacts/Verification/**`은 기준선과 결함 근거일 뿐 Wave 3 완료 증거를 대신하지 않는다.

- `baseline-integrity.txt`: clean 여부, HEAD, Unity 버전, 빌드 대상
- `deterministic-three-day.txt`: 본선 3회, 숙련 2회, 탈진·강제 귀환·기한 실패
- `playtest-day1-3.csv`, `playtest-summary.md`: 인간 6명 계측
- `localization-contract.json`: 138키 coverage·placeholder·중복·고아·fallback 결과
- `save-locale-invariance.txt`: ko→en→qps-long→ko 진행 상태 비교
- `world-label-metrics.txt`, `placement-visual-review.txt`: 1280×800 원본 판독
- `playmode-{ko,en,qps-long}-{camp,swim,inventory,result}-1280x800.png`
- `physical-gamepad.txt`: 실제 장치가 있을 때만 PASS
- `windows-release-build.txt`: 수직 슬라이스 후보의 Windows x64 빌드·시작·정상 종료

최종 **GO**는 다음을 모두 만족할 때만 선언한다.

1. 다음 구현 가능 4건이 완료되고 각각 새 증거가 있다.
2. 본선·숙련·실패 경로와 인간 표본이 3·4절을 통과한다.
3. ko/en/qps-long의 138키, 폰트, 1280×800, 입력 프롬프트와 저장 불변성이 통과한다.
4. P1 0건이며, 남은 P2는 실제 게임패드 장치 부재처럼 외부 조건이 명시된 QA 공백뿐이다.
5. Steam 출하 항목은 완료로 위장하지 않고 `수직 슬라이스 이후` 상태를 유지한다.

하나라도 충족하지 못하면 **NO-GO**다. 수치가 목표 밖일 때는 4절의 조정 순서를 따르고, 동시에 둘 이상의 경제 축을 변경하지 않는다.

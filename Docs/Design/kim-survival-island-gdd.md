## 0. 문서 사용법

이 문서는 사람이 읽는 최신 통합 기획서다. 구현에 사용되는 안정 ID, 구조화 데이터, 테스트 계약의 기계 정본은 `.forge/design/project.json`과 `.forge/design/vertical-slice.json`이다.

내용이 충돌할 때는 다음 순서를 따른다.

1. 이후 사용자가 명시적으로 확정한 결정
2. 같은 결정이 반영된 최신 `.forge/design/` 정본
3. 이 통합 GDD
4. 개별 `Docs/Design/wave*.md` 문서
5. 과거 3일·5일 프로토타입 문서와 플레이테스트 기록

과거 문서에 남아 있는 `3일/5일 데드라인`, `6지역`, `7위험`, `19엔딩`, `밧줄로 숲 장벽 통과`는 현재 기획이 아니다. 최신 기준은 **표준 Day 50, 최소 7지역, 9위험, 21엔딩, 돌도끼로 덩굴·나무 장벽 제거**다.

이 문서에서 사용하는 상태 표기는 다음과 같다.

| 표기 | 의미 |
|---|---|
| `CONFIRMED` | 게임의 방향과 규칙으로 확정된 내용 |
| `PROVISIONAL` | 구현·플레이테스트용 표본이며 수치 조정 가능 |
| `GAME JAM` | 한 달 게임잼 출품용 버티컬 슬라이스 범위 |

| `UNVERIFIED` | 설계 또는 자동 검증은 있으나 자연 사용자·실기기 증거가 없는 상태 |

| 항목 | 내용 |

| 제목 | 《김씨 생존기: 무인도》 |
| 시리즈 | 《김씨 생존기》 첫 작품. 바다·산·광산·하늘·우주 등 독립 부제를 붙여 확장 가능 |
| 장르 | 코믹 2D 횡스크롤 거점 생존, 유한 자원 수색, 제작·건설, 행동 기반 다중 엔딩 |

### 1.1 한 줄 소개

무인도에 조난된 평범한 김씨가 무엇이 들었는지 모르는 환경 수색물을 뒤져 필요한 것만 가방에 챙기고, 영구히 변하는 일곱 지역과 위아래로 확장되는 캠프를 오가며 여러 방식으로 탈출하거나 기묘한 섬 생활의 결말을 맞는 코믹 생존 게임.

### 1.2 플레이어 약속

> 섬의 흔적을 직접 뒤지고, 발견한 것 중 지금 필요한 것만 골라 담아, 내가 선택한 생존 방식과 탈출 계획으로 나만의 김씨 엔딩을 만든다.

### 1.3 차별점

- 바닥에 놓인 자원을 차례로 줍는 게임이 아니라, 풀숲·바위틈·표류물 더미 같은 장소를 뒤져 결과를 확인하고 필요한 발견물을 선택한다.
- 다녀온 지역은 초기화되지 않는다. 남겨 둔 물건, 고갈된 수색물, 부순 장벽, 제거한 위험이 같은 run에 계속 남는다.
- 하나의 정답 루트 대신 최소 다섯 탈출법과 다수 엔딩 후보가 다음 원정의 목적을 바꾼다.
- 베이스캠프는 전역 관리 메뉴가 아니다. 김씨가 설비까지 직접 걸어가 사용하고, 2층과 지하실을 실제 공간으로 증축한다.
- 플레이 중 반복한 수영·농사·사냥·기계공학·건설·수색·위험 대응이 엔딩의 직업과 농담에 반영된다.

### 1.4 레퍼런스 경계

- 《This War of Mine》은 측면 공간에서 인물이 설비까지 직접 이동해 상호작용하고 거주 공간을 확장하는 감각의 가장 가까운 참고 방향이다. 다만 고유 UI, 건물 구조, 미술, 문구는 복제하지 않는다.
- 《Moonlighter》와 《Dave the Diver》에서는 “밖에서 수집 → 안전한 거점으로 귀환 → 다음 수집 능력에 투자”하는 루프의 명료함만 참고한다.
- 이 게임은 상점 판매 루프가 아니다. 수집한 물자를 생존, 치료, 제작, 연구, 캠프 확장, 탈출에 사용한다.

## 2. 디자인 기둥

### 2.1 다녀온 섬은 그대로 남는다

자원 고갈, 알려진 잔여물, 제거한 장벽, 남겨 둔 위험, 획득한 보호 핵심 부품을 stable ID로 저장한다. 재방문은 새로운 주사위 굴림이 아니라 플레이어가 만든 상태의 연속이어야 한다.

### 2.2 탈출법이 수색 계획을 바꾼다

대형 연기는 막대한 나무와 부싯돌을, 무전 구조는 서로 다른 지역의 망가진 무전기·전자기판·트랜지스터를 요구한다. 탈출법마다 지역, 연구, 설비, 장비, 날씨 조건 중 최소 두 축 이상이 달라야 한다.

### 2.3 캠프와 김씨의 삶이 위아래로 자란다

지붕이 있는 시작층·2층·지하실을 직접 연결한다. 탈출 장비·모닥불·사다리와 구조 연결부는 안전한 고정 지점을 사용하고, 나머지 일반 설비와 가구는 완성된 방 안에서 통로를 지키며 자유롭게 배치·재배치한다. 어떤 공간과 설비에 투자했는지, 그곳에서 어떤 행동을 반복했는지가 생존 능력과 엔딩 정체성을 함께 만든다.

### 2.4 위험은 예고하고, 선택을 요구하고, 회복시킨다

위험은 갑자기 결과만 빼앗는 랜덤 벌점이 아니다. 예고 → 노출 또는 선택 → 효과 → 완화·치료의 흐름을 갖는다. 손실은 원자적으로 한 번만 적용하며 회복 경로를 남긴다.

### 2.5 코미디는 규칙을 가리지 않는다

김씨는 영웅보다 생활인에 가깝다. 건조한 독백과 상황 과장은 사용하되, 필요한 재료·위험·실패 원인을 농담이 가리면 안 된다. 한국어가 의미와 톤의 기준 원문이며 영어는 같은 기능을 자연스럽게 재창작한다.

## 3. 경험 목표와 플레이 프로필

### 3.1 게임잼용 30분 버티컬 슬라이스

| 시간 | 플레이어가 경험해야 하는 것 |
|---:|---|
| 0~5분 | 캠프를 직접 걷고 설비·수집 지도와 근접 상호작용, 오늘의 후보 지역 비교 |
| 5~10분 | 첫 지역에서 환경 수색물을 뒤지고, 숨겨진 발견물 중 일부만 가방에 선택해 귀환 |
| 10~20분 | 생존 회복과 제작·연구·가방 또는 다층 캠프에 투자하고 다음 탈출 재료를 추적 |
| 20~27분 | 장벽·수영·질병 또는 다른 위험을 경험하고, 탈출 프로젝트의 마지막 단계를 준비 |
| 27~35분 | 뗏목·대형 연기·무전 중 하나로 탈출하고 행동 근거가 반영된 3~5컷 엔딩 확인 |

게임잼 빌드는 표준 50일을 그대로 30분 동안 반복시키지 않는다. 별도의 `GAME JAM` 페이싱 프로필로 이동·수색·제작 시간을 압축하되, 중간 자원 지급이나 순간이동 없이 실제 인터페이스와 거래를 거쳐야 한다.

장기 체류 반복 플레이 검증용으로 **Day 20 전후의 임시 판정 프로필**을 둘 수 있다. 이 값은 `PROVISIONAL`이며 표준 캠페인의 Day 50을 대체하지 않는다.

### 3.2 표준 캠페인

- 기본 데드라인은 Day 50이다.
- Day 50 이전에도 조건을 충족하면 언제든 즉시 탈출할 수 있다.
- 날짜 구간은 권장 페이싱이지 퀘스트식 하드 잠금이 아니다.
- Day 50에 탈출을 완료하지 못하면 누적 행동에 따라 장기 체류 엔딩 하나를 결정한다.
- 추후 사용자 설정 플레이에서 데드라인, 위험도, 자원 풍부함 등을 조정할 수 있으나 게임잼 범위는 아니다.

| 구간 | 의도 |
|---|---|
| Day 1~10 | 해변·숲·얕은물 비교, 첫 캠프→지도→수색→귀환→정산 루프 학습 |
| Day 11~20 | 장비·발견·연구로 첫 확장 지역 개방, 짧고 먼 원정 비교 |
| Day 21~35 | 여러 탈출 프로젝트와 캠프 보호 사이에서 투자·전환 |
| Day 36~49 | 완성·수리·경로 전환, 남은 날짜 압박과 회복 가능한 위험 |
| Day 50 | 그날 탈출 성공을 우선 판정하고, 아니면 하나의 장기 체류 엔딩으로 종료 |

### 3.3 성공 지표

- 설명자 개입 없이 첫 사용자가 10분 안에 수색물을 뒤지고 일부를 골라 귀환한 뒤 자원을 투자한다.
- fresh run의 70% 이상이 `GAME JAM` 프로필에서 25~35분 안에 뗏목·연기·무전 엔딩 중 하나에 도달한다.
- 진행 불가능 seed가 없어야 하며, seed별로 최소 세 탈출 경로의 완성 가능성을 보장한다.
- 플레이어가 엔딩 뒤 “내 행동 때문에 이 결말이 나왔다”는 근거를 설명할 수 있다.

## 4. 핵심 플레이 루프

```text
캠프에서 상태·설비·탈출 목표 확인
              ↓
수집 지도 오브젝트에 직접 접근
              ↓
7지역의 자원 전망·위험·장비·고갈도 비교
              ↓
한 지역으로 출발해 이동·수영·장벽·위험 대응
              ↓
환경 수색물을 뒤져 발견물 공개
              ↓
가방에 담기 / 교체 / 남겨 두기
              ↓
귀환하여 생존·치료·제작·연구·증축·탈출에 투자
              ↓
하루 정산과 세계 상태 저장
              ↓
다른 지역·다른 탈출법·다른 엔딩을 향해 반복
```

### 4.1 하루의 기본 흐름

1. **아침·캠프 준비**: 날짜, 일광, 허기, 체력, 상태 이상, 가방, 현재 탈출 목표를 확인한다.
2. **현장 행동**: 김씨가 설비로 걸어가 회복, 식사, 제작, 연구, 건설, 재배치, 프로젝트 투자를 한다.
3. **지역 선택**: 지도 설비에서 자원 전망, 위험도, 날씨, 필요 장비, 남은 자원, 부품 단서를 비교한다.
4. **원정**: 선택 지역을 횡스크롤로 탐색하고 수영·도구·위험 판단을 수행한다.
5. **수색**: 환경 수색물을 뒤져 발견물을 공개하고 가방에 선별한다.
6. **귀환**: 자발적으로 귀환하거나 일광이 끝나기 전에 복귀한다.
7. **정산**: 허기와 상태 변화, 예고된 위험, 캠프 효과를 원자적으로 처리한다.
8. **다음 날 또는 엔딩**: 탈출이 완료되면 즉시 엔딩, 아니면 다음 날로 진행한다.

하루 원정은 기본 1회다. 이미 수색을 마친 날 지도를 다시 열거나 출발을 시도하면 아무 반응 없이 막지 말고 “오늘 수색은 끝났다. 캠프를 정리하고 다음 날로 넘어가자.”라는 원인 안내를 표시한다.

### 4.2 플레이어 동사

이동, 접근, 상호작용, 지역 비교, 뒤지기, 발견물 선별, 수영, 장벽 제거, 위험 회피·제거, 운반, 먹기, 치료, 제작, 연구, 건설, 재배치, 탈출 시도.

## 5. 베이스캠프

### 5.1 공간 원칙

- 베이스캠프는 상시 대형 관리 대시보드가 아니다.
- 김씨가 같은 공간을 직접 이동해 설비의 1.25u 상호작용 범위 안으로 접근해야 한다.
- 가까운 대상 하나만 안내하고, 상호작용 뒤 해당 설비의 작은 전용 팝업을 연다.
- 팝업을 닫거나 취소하면 김씨는 원래 위치·방향·방으로 돌아간다.
- 김씨나 필수 통로를 막는 배치는 확정할 수 없다.
- 설치·미리보기·취소 자체는 체력, 허기, 일광을 소모하지 않는다.

### 5.2 캠프 구조

```text
                [2층 표준 모듈]
                       │ 사다리/연결부
[옆방 표준 모듈] ─ [시작층] ─ [해안 진수대·고정 신호 앵커]
                       │ 해치/사다리
                [지하실 표준 모듈]
```

- `CONFIRMED`: 시작층은 처음부터 비와 햇빛을 막는 지붕과 절개형 실내 윤곽을 갖는다. 시작층, 2층, 지하실을 같은 측면 절개 쉘터의 위·아래 성장으로 읽을 수 있어야 한다.
- O8부터 **하이브리드 제한적 자유 배치**를 사용한다. 작업대·빗물받이·침대·소파 등 일반 설비는 완성된 현재 방의 바닥 범위에서 포인터·방향키·게임패드로 연속 이동하고 원하는 위치에 확정한다.
- 일반 설비는 `StableRoomId + 방 내부 정규화 좌표`로 저장한다. 벽, 다른 설비 footprint, 출구, 문, 해치, 사다리, 김씨와 설비의 사용 공간, 필수 통로를 침범하면 확정할 수 없다.
- 일반 설비는 시작층·2층·지하실 사이에서 무료로 재배치할 수 있고 기능·연구 상태를 보존한다.
- 해안 진수대·대형 연기·무전 등 탈출 장비, 모닥불, 사다리와 증축 연결부만 `StableRoomId + StableAnchorId` 전용 고정 지점을 사용한다.
- 게임잼에서는 2층과 지하실을 모두 지어 각 공간에 일반 설비를 배치하고 직접 사용 가능해야 한다. 옆방은 표준 시스템 검증용 후보지만 필수 완성 목표에서는 제외할 수 있다.

### 5.3 상호작용 대상과 행동 소유권

| 대상 | 가능한 행동 | 하지 않는 행동 |
|---|---|---|
| 저장·설계점 | 창고·가방 보기, 식사, 미건설 설비 계획, 위층·지하실·옆방 연결부 미리보기 진입 | 제작·연구·가방 구매·탈출 투자 |
| 연결 슬롯 | 위·옆·지하 모듈 미리보기와 유효성 확인 | 원거리 설비 사용 |
| 작업대 | 도구 연구·제작, 가방 4→6→8→10 확장 | 식사·휴식·모듈 직접 결제·탈출 프로젝트 투자 |
| 모닥불 | 현재 회복 효과 확인, 전용 고정 지점 사용 | 전역 제작·연구 메뉴·자유 배치 |
| 빗물받이 | 정산 효과 확인, 완성된 세 층의 유효 영역에 자유 배치·재배치 | 연구·통로 차단 |
| 침대 | 휴식 준비, 완성된 세 층의 유효 영역에 자유 배치·재배치 | 제작·연구 |
| 소파 | 편안한 휴식 준비, 완성된 세 층의 유효 영역에 자유 배치·재배치 | 제작·연구 |
| 수집 지도·출구 | 지역 비교, 오늘의 원정 시작 | 이미 다녀온 날 무응답 처리 |
| 해안 진수대 | 뗏목 단계 확인·투자·출항 | 다른 탈출법 투자 |
| 대형 연기 설비 | 연료·부싯돌·신호 유지와 기상 창 확인 | 외부 전용 고정 설치 지점 |
| 무전 작업대 | 무전 부품·전원·주파수 복구 | 부품 없이 완료 |

### 5.4 상호작용 대상 선택 우선순위

동시에 여러 대상이 가까울 때는 다음 순서로 하나만 선택한다.

1. 현재 적격 대상으로 유지 중인 latch
2. 완성되어 실제 사용할 수 있는 설치 설비
3. 김씨가 바라보는 방향의 대상
4. 더 가까운 대상
5. 안정 `InteractionTargetId` 오름차순

설치 설비와 모듈 연결부가 겹치면 작업대 같은 **완성 설비가 연결부 미리보기보다 우선**한다. 모듈 미리보기는 연결 슬롯에 명시적으로 접근하거나 설계점에서 선택했을 때만 연다.

### 5.5 캠프 성장

| 성장 | 현재 계약 |
|---|---|
| 작업대 | 제작·연구·가방 확장의 중심 설비 |
| 돌도끼 | 덩굴·쓰러진 나무 장벽을 상호작용으로 제거, 나무 수색 결과 +1. 소비·내구도 없음 |
| 밧줄 | 탈출·장비 요구의 선행 보유품. 숲 장벽 제거 도구가 아님 |
| 가방 | 4칸으로 시작해 작업대에서 6→8→10칸까지 매번 2칸씩 단계 확장. 한 묶음 최대 2개가 현재 기준 |
| 2층·지하실 | 작업대 이후 확정 가능한 표준 모듈. 정확한 비용은 `PROVISIONAL` |
| 일반 설비 | 현재 방의 호환 빈 설치 지점을 골라 배치. 좌표 미세 조정 없음 |

과거 프로토타입의 정확한 비용은 현재 50일 캠페인의 최종 밸런스가 아니다. 경제 수치는 한 번에 한 축씩 자연 플레이테스트로 조정한다.

## 6. 수집 지도와 일곱 지역

### 6.1 지도 정보 계층

지도는 “오늘 어디로 갈 것인가”를 결정하는 전략 화면이다. 각 지역 카드는 다음을 색상만이 아닌 아이콘과 문구로 함께 표시한다.

- 지역명과 잠금·해금 상태
- 이동 시간대: 짧음·보통·장거리
- 자원 전망: 풍부·보통·희귀 범주
- 전체 고갈도와 알려진 잔여 수색물
- 위험도, 확인된 위험, 날씨 예보
- 필요한 도구·장비와 정확한 잠금 이유
- 발견한 특수 단서와 보호 핵심 부품 후보
- 오늘 원정 가능 여부

새 게임에서는 해변만 열려 있다. 현재 해금된 최전선 지역에 처음 진입하는 순간 다음 지역 하나를 영구 해금한다. 잠긴 지역은 숨기지 않고 실루엣, 순서, “이전 지역 첫 진입” 조건을 표시하되 출발 버튼은 비활성화한다. 장비는 지역 자체를 잠그는 열쇠보다 그 안의 추가 수색물·장벽·위험 완화 수단으로 사용한다.

### 6.2 지역 목록

지역명은 아트 제작 전까지 작업명이며 안정 ID는 유지한다.

| 안정 ID | 작업명 | 해금 | 대표 자원 | 대표 위험·조건 | 특별 단서·부품 후보 |

### 6.3 O8 단계별 초반 경제 하한

- 해변의 도구 없는 수색물 전체에는 식량 2 이상과 나무·표류물 합계 4 이상을 반드시 둔다. 첫날 귀환, 식사, 기초 생존 투자가 seed 때문에 막히면 안 된다.
- 숲의 도구 없는 수색물 전체에는 식량 1 이상과 돌 2 이상을 반드시 둔다. 돌도끼는 숲 진입 허가증이 아니라 추가 수색물·장벽·수율을 여는 첫 성장 도구다.
- 이후 각 지역은 대표 자원만 배타적으로 내지 않는다. 환경상 타당한 보조 자원 2종 이상과 다음 단계 제작에 필요한 후보를 섞는다.
- 보장 하한은 각 node의 정확한 내용물을 미리 보여 주지 않는다. ‘어딘가를 더 뒤지면 진행에 필요한 것이 있다’는 총량만 보장하고 위치는 seed로 달라진다.

### 6.4 지역 상태 지속성

같은 run에서 다음 상태를 지역별로 저장한다.

- 각 수색물의 `미확인 / 확인·잔여 있음 / 고갈` 상태
- 최초 공개된 발견물과 남겨 둔 수량
- 돌도끼로 부순 장벽과 열린 통로
- 제거한 위험, 남은 둥지·독초·함정, 이미 발동한 사건
- 획득·손상·수리한 보호 핵심 부품
- 지역 해금, 발견 단서, 익숙해진 이동 시간대

게임잼 필수 저장 범위는 **한 run 안의 재방문**이다. 게임을 종료한 뒤 이어하기 세이브는 정식 버전 범위로 미룰 수 있다.

## 7. 환경 수색 오브젝트와 발견물 선별

### 7.1 기본 원칙

일반 자원과 탈출 핵심 부품의 주 획득 방식은 작은 스프라이트를 하나씩 줍는 것이 아니다. 월드에 보이는 작은 물건은 장식 또는 수색 단서이며, 실제 획득은 다음 환경 수색물을 통해 이뤄진다.

- 풀숲
- 바위틈
- 표류물 더미
- 나무 구멍
- 난파선 수납함
- 폐시설 캐비닛·부품함

처음 뒤지기 전에는 정확한 아이템과 수량을 숨기고 오브젝트 종류, 지역 전망, 위험 단서만 제공한다.

게임잼 O6 밀도 기준은 일곱 지역 합계 **84개 stable 수색물**이다. 기존 수색물 하나의 내용물을 일괄 3배로 불리는 방식은 사용하지 않는다. 수색물별 발견량은 소량·중간·다량을 섞고, 한 트레이가 항상 과밀하지 않게 한다. 일반 자원 총량 432단위는 유지하되 더 많은 장소에 분산하며, 보호 핵심 부품은 일반 발견물 뒤에 잘려 보이지 않고 반드시 발견·선택 가능해야 한다.

### 7.2 결정론과 재방문

1. 새 run 생성 시 `run seed + stable node ID`로 수색물 내용물을 한 번 결정한다.
2. 플레이어가 뒤지면 시간·체력·위험 노출을 지불하고 내용물을 공개한다.
3. 가져간 발견물만 원자적으로 가방으로 이동한다.
4. 두고 간 것은 같은 수색물에 알려진 잔여물로 남는다.
5. 취소, 화면 전환, 언어 변경, 재방문으로 내용물을 다시 추첨하지 않는다.
6. 모든 발견물을 가져가면 고갈 상태가 지속된다.

이 규칙은 “열었다 닫아서 좋은 결과가 나올 때까지 재추첨”하는 파밍을 금지한다.

### 7.3 발견물 선택 트레이

- 발견물은 compact 트레이에 표시하되 그 수색물에서 공개된 항목을 네 개로 자르지 않고 모두 표시한다.
- 트레이가 열린 동안 왼쪽에는 교체 필요 여부와 무관하게 현재 가방의 모든 칸·수량·용량을 항상 표시한다.
- 상시 가방은 캐릭터 발 아래의 좌측 하단 안전영역에 놓고 1280×800 기준 화면 폭 24%를 넘지 않는다. 각 칸은 가로로 길게 늘이지 않고 아이콘·짧은 이름·수량 중심으로 표시한다.
- 가방에 빈칸이 있으면 빠르게 담을 수 있다.
- 가방이 가득 차면 기존 묶음과 새 발견물을 비교해 **교체**하거나 **남겨 두기**를 선택한다.
- 핵심 부품도 같은 발견 결과에서 나타나지만 보호 인벤토리로 옮겨 일반 도난·캠프 피해로 삭제되지 않게 한다.
- 선별 UI가 열린 동안 새 공격·위험 판정을 멈춘다. 메뉴를 읽는 시간을 벌하지 않는다.
- 남은 일광, 체력, 질병 노출, 현재 탈출 목표가 선별 판단에 함께 보이도록 한다.

### 7.4 장벽과 수영

- 녹색 덩굴·쓰러진 나무 장벽은 돌도끼를 만든 뒤 현장에서 직접 상호작용해 제거한다.
- 도끼를 보유했다고 자동으로 사라지지 않으며, 제거 상태는 다음 날과 재방문에도 유지한다.
- 밧줄만으로 숲 장벽을 열 수 없다.
- 해안·얕은물 지역에는 수영으로 접근하는 수색물이 있다.
- 수영은 이동·체력·부상·질병 노출과 행동 통계에 영향을 주되 깊은 잠수 게임으로 확대하지 않는다.

## 8. 자원, 인벤토리, 제작과 연구

### 8.1 자원 범주

| 범주 | 용도 예 |
|---|---|
| 나무·돌·섬유·천 | 캠프, 도구, 뗏목, 연기 설비 |
| 식량·물·약품 | 허기, 회복, 질병 치료, 항해 보급 |
| 표류물·금속 | 설비, 수리, 구조 프로젝트 |
| 전선·전자부품·연료·화학재 | 무전, 중계소, 조명탄, 고급 장비 |
| 보호 핵심 부품 | 특정 탈출법을 여는 고유 진행물 |

정확한 비용, 드롭 수량, 회복량, 위험 빈도는 `PROVISIONAL`이다. 50일 캠페인에서 캠프 성장에 투자했다고 모든 탈출 경로가 잠기는 경제를 허용하지 않는다.

### 8.2 가방

- 수색 가방은 4칸으로 시작한다.
- 한 칸의 현재 묶음 상한은 2개다.
- 작업대에서 4→6→8→10칸 순서로 매번 2칸씩 확장할 수 있다. 각 단계는 독립 비용과 성공 상태를 저장한다.
- 가방 확장은 수색의 선택 압박을 완전히 지우지 않고 중반 성장 보상으로 작동해야 한다.
- 초과 발견물은 자동 삭제하거나 창고로 순간이동시키지 않는다. 플레이어가 무엇을 남길지 선택한다.

### 8.3 연구·제작 원칙

- 작업대를 먼저 설치하고 직접 접근해야 제작·연구 팝업을 사용할 수 있다.
- 작업대 root에는 제작, 연구, 가방 확장만 노출한다.
- 미리보기와 취소는 자원을 바꾸지 않는다.
- 건설·증축은 자원 부족 등으로 실패해도 팝업을 닫지 않고 같은 팝업 안에 원인을 표시한다.
- 연구는 성공과 실패 모두 작업대 팝업을 유지하고 결과 메시지를 표시해 연속 행동과 비교를 허용한다.
- 모든 성공 거래는 조건 확인과 차감을 하나의 원자 transaction으로 처리한다.
- 도구와 프로젝트 단계는 언어 문자열이 아닌 안정 ID로 저장한다.

게임잼 필수 도구·장비는 돌도끼, 밧줄, 수영 준비, 광원, 방수·절연 장비의 최소 표현이다. 각 장비는 새로운 지역·수색물·위험 완화 중 적어도 하나의 명확한 역할을 가져야 한다.

## 9. 생존과 위험

### 9.1 공통 위험 흐름

```text
지도·월드·HUD에서 예고
          ↓
회피 / 장비 사용 / 위험을 감수하고 진행
          ↓
노출·사건을 한 번 원자 처리
          ↓
명명된 상태와 명확한 불이익
          ↓
치료 / 휴식 / 수리 / 다음 위험 완화
```

위험은 즉사 함정이 아니라 계획을 흔드는 선택 비용이다. 한 사건이 식량 도난과 설비 파손을 독립적으로 이중 차감할 수 없고, 주요 위험 뒤에는 회복 가능한 날을 둔다.

### 9.2 위험 카탈로그

| 안정 ID | 예고 | 효과 | 대응·회복 |
|---|---|---|---|
| `hazard.hunger` 허기 | HUD 추세와 다음 정산 예상 | 임계 단계에서 체력·행동 불이익 | 먹기, 보존식·농사 준비, 짧은 원정, 휴식 |
| `hazard.disease` 질병 | 지역 노출원과 잠복 표시 | 미처치 노출이 시간형 질병으로 진행 | 약품, 깨끗한 물, 건조 장비, 회복일 |

| `hazard.camp-damage` 캠프 피해 | 대상 설비와 피해 유형 표시 | 설비 하나가 작동→손상 | 보강, 덮개, 예방 정비, 원자 수리 |

### 9.3 공정성 계약

- critical hunger는 랜덤 roll이 아니라 예측 가능한 상태다.
- 첫 도난·파손은 예고 없이 바로 손실로 건너뛰지 않는다.
- 보호 핵심 부품과 완료한 탈출 단계는 일반 위험으로 삭제되지 않는다.
- major 위험 다음 날은 같은 계열의 새 major를 억제하고 회복 예산을 남긴다.
- Day 50에는 새 기습 도난·캠프 파손 major를 만들지 않는다.
- 게임잼 플레이에서는 벌레·야생동물·위험 식물 중 최소 두 종류와 질병 하나를 예고부터 치료·완화까지 완결해 보여 준다.

## 10. 탈출 프로젝트

### 10.1 공통 규칙

- 전체 카탈로그는 최소 다섯 탈출법이다.
- 게임잼에서 플레이 가능한 경로는 뗏목, 대형 연기, 무전 구조 세 가지다.
- 조명탄과 고지대 중계소는 안정 ID와 설계·데이터를 유지하지만 `DEFERRED`다.
- 핵심 부품은 여러 지역의 수색물에 흩어 놓는다.
- preview와 취소는 무변경, 확정은 한 transaction, 실패는 선언된 손실만 한 번 적용한다.
- 실패가 완료 단계나 핵심 부품을 영구 삭제해서는 안 된다.
- seed 생성과 중요 진행 시점마다 최소 세 경로가 완성 가능한지 감사하고, 실패하면 미획득 핵심 부품 배치만 다시 정한다.
- 동일 부품을 충분히 찾지 못하면 eligible-search 기반 단서와 pity를 제공하되 정확한 횟수는 `PROVISIONAL`이다.

### 10.2 탈출법 요약

| ID | 상태 | 핵심 판타지 | 필수 차별 요소 |
|---|---|---|---|
| `escape.raft` | `GAME JAM PLAYABLE` | 직접 엮은 뗏목·소형 범선으로 조류를 타고 탈출 | 선체, 보호 돛천, 항해 보급, 해안 진수대, 날씨·조류 창 |
| `escape.smoke` | `GAME JAM PLAYABLE` | 고지대의 대형 연기를 며칠 유지해 발견 | 막대한 나무, 보호 부싯돌, 고정 설비, 풍향·비, 신호 유지 |
| `escape.radio` | `GAME JAM PLAYABLE` | 흩어진 기계 부품으로 좌표를 송신 | 망가진 무전기, 전자기판, 트랜지스터, 전원, 주파수·안테나 |
| `escape.flare` | `DEFERRED` | 구조 대상이 보이는 짧은 창에 조명탄 한 발 | 보호 탄약, 화공, 일회 발사기, 목격 창, 불발·오발 |
| `escape.beacon` | `DEFERRED` | 폐중계소 발전기와 신호등을 복구 | 구조물·발전기·신호등 3단계, 발전 코일, 폭풍·낙뢰 |

### 10.3 뗏목 탈출

1. 해변·얕은물·난파선 만을 수색해 나무·섬유·천·식량·물과 보호 돛천을 찾는다.
2. 해안 진수대에서 선체 → 돛 → 항해 보급 단계를 진행한다.
3. 안전한 날씨와 바깥 방향 조류 창을 확인한다.
4. 출항 성공 시 뗏목 계열 엔딩, 지연·표류 귀환·선체 손상 시 해당 결과만 적용한다.
5. 출항 실패나 취소로 완성 단계와 보호 돛천을 잃지 않는다.
6. 항해 보급은 3단계에서 한 번만 납입한다. 3/3 뒤에는 오늘 출항 가능 여부와 다음 입력을 명시하며, 닫힌 날의 확인·재시도는 식량을 포함한 자원을 소모하지 않는다.
7. 선체·돛·보급·날씨·조류 확인과 최종 `출항`은 모두 같은 해안 진수대 팝업에서 진행한다. 별도의 위치를 알 수 없는 ‘출항창’을 찾게 하지 않는다.
8. 다음 단계나 출항이 불가능하면 팝업을 닫지 않고 화면 중앙 약간 상단 토스트에 부족 재료·보호 부품·날씨·보급 중 정확한 이유 하나를 표시한다.

### 10.4 대형 연기 구조

1. 숲·동굴·고지대 수색물에서 보호 부싯돌을 찾는다.
2. 일반 캠프 소비와 경쟁할 만큼 많은 나무를 확보한다. 정확한 총량은 플레이테스트 전 `PROVISIONAL`이다.
3. 고정 연기 설비를 여러 단계로 준비하고 연료를 유지한다.
4. 비·강풍·풍향을 읽어 보이는 신호 창을 지킨다.
5. 날씨 실패는 그날 선언된 연료만 소모하며 설비와 부싯돌을 삭제하지 않는다.

### 10.5 무전 구조

1. 서로 다른 지역의 환경 수색물에서 다음 세 부품을 모두 찾는다.
   - 망가진 무전기 또는 송수신기 `part.radio.transceiver`
   - 망가진 전자기판 `part.radio.circuit-board`
   - 트랜지스터 `part.radio.transistor`
2. 무전 작업대에서 수리·전원·안테나 단계를 진행한다.
3. 정확한 주파수와 위치를 송신해 유효 응답을 받는다.
4. 실패 송신은 사건 하나만 기록하고 부품을 재추첨·삭제하지 않는다.

### 10.6 후속 탈출법

조명탄은 한 발의 타이밍 선택, 고지대 중계소는 장기 수리와 폭풍 대응을 담당한다. 게임잼에서는 지도 단서, 엔딩 카탈로그, 데이터 무결성까지만 보여 줄 수 있으며 “플레이 가능”으로 홍보하지 않는다.

## 11. 행동 기반 엔딩과 반복 플레이

### 11.1 판정 원칙

- 탈출 완료는 Day 50 정산보다 우선한다.
- 후보 우선순위는 `희귀 → 코믹 → 일반 → 장기 체류 생활형 → fallback`이다.
- 같은 계층에서는 안정 priority, 조건 수, 사건 발생일, ending ID 순으로 하나만 고른다.
- 입력 횟수나 이동 시간은 세지 않고 완료된 의미 행동만 점수화한다.
- 마지막 탈출 버튼 한 번으로 평생의 정체성이 뒤집히지 않게 우세 행동에 히스테리시스를 둔다.
- core ending ID는 하나이며 우세 행동 modifier 1장과 사건 흔적 modifier 1장을 추가할 수 있다.

| Day 50 | `ending.stay.green-king` | 김씨 농장 50일째 | 미탈출 + 농사 우세 |
| Day 50 | `ending.stay.fortress-manager` | 무인도 관리사무소 | 미탈출 + 건설·위험 대응 우세 |
| Day 50 | `ending.stay.scrap-professor` | 표류물 공학 박사 | 미탈출 + 기계·수색 우세 |
| Day 50 | `ending.stay.island-ranger` | 섬의 레인저 | 미탈출 + 수영·사냥 우세 |
| Day 50 | `ending.stay.just-kim` | 그냥 잘 사는 김씨 | 다른 생활형 후보가 없는 미탈출 fallback |

게임잼에서 21개 엔딩의 완성 컷신을 모두 만들 필요는 없다. 카탈로그와 안정 ID는 모두 유지하고, 뗏목·연기·무전 대표 엔딩과 두 장기 체류 엔딩을 우선 제작한다.

### 11.4 엔딩 표현

- 엔딩 하나는 3개의 core panel beat로 구성한다.
- 우세 행동과 특별 사건에 따라 최대 2개 modifier panel을 끼워 총 3~5컷으로 만든다.
- 화면은 짧은 코믹북·움직이는 컷신 형태이며 결과, 원인, 후일담을 분명히 보여 준다.
- 엔딩 갤러리 “김씨의 생존 앨범”에는 발견한 엔딩, 미발견 실루엣, 다음 run 힌트를 표시한다.
- 각 ending ID는 향후 Steam 업적 ID와 1:1 매핑할 수 있지만 Steamworks 실제 연동은 `DEFERRED`다.

### 12.2 캠프 정보 계층

- 지속 HUD: Day, 일광, 허기, 체력, 핵심 상태, 활성 가방 4/6/8/10과 compact 자원 요약.
- 내레이션: 상단의 짧은 상황 문장.
- 근접 안내: 내레이션 아래 중앙 상단에 대상 하나만 한 줄로 표시.
- 설비 팝업: 최대 약 420×360px, 화면 높이 45% 이내의 작은 상황형 창.
- 하단 도움말: 현재 입력 장치의 이동·확정·취소 glyph.

근접 안내는 월드 길 위나 김씨 얼굴 위의 큰 검은 카드가 아니다. 현재 기준 높이는 48px이고 한 줄을 유지한다. 팝업·배치·증축 화면이 열리면 안내를 숨긴다.

화면 우선순위는 `결과·시스템 모달 > 설비 팝업·미리보기 > 근접 안내 > 월드`다. 같은 시점에 여러 상호작용 카드와 배치 네모가 겹쳐 플레이 공간을 가리지 않게 한다.

### 12.3 배치 피드백

배치 미리보기는 유효 영역을 전부 불투명한 네모로 덮지 않는다. 선택 중인 유령, 바닥 스냅선, 현재 실패 원인만 강조한다.

실패 원인은 우선 하나를 명확히 표시한다.

1. 해당 모듈·구역과 호환되지 않음
2. 다른 설비와 겹침
3. 김씨 또는 설비의 사용 공간 부족
4. 출구·문·사다리·필수 통로 차단
5. 탈출 장비·모닥불·구조 연결부의 고정 앵커 불일치
6. 자원 또는 선행 설비 부족

취소·무효 위치·중복 Submit으로 자원이나 설비 상태가 바뀌지 않는다.

### 12.4 가독성·접근성

- 기준 해상도 1280×800과 1920×1080에서 검증한다.
- 본문 18px, 버튼·핵심 수치 20px 미만 축소로 문제를 숨기지 않는다.
- 색상만으로 위험·유효·잠금 상태를 구분하지 않고 아이콘·텍스트를 병용한다.
- 실제 지원 ko/en에서 핵심 설비명과 요구조건에 의미를 숨기는 말줄임표를 사용하지 않는다.
- 김씨, 활성 설비, 주 이동 통로를 동시에 완전히 가리는 UI가 없어야 한다.

## 13. 입력과 현지화

### 13.1 입력

공통 액션은 `Move`, `Interact`, `Navigate`, `Submit`, `Cancel`, `Bag`, `Pause`로 정의하고 Unity Input Action에 연결한다.

- 키보드·마우스와 게임패드는 같은 게임 상태와 거래를 사용한다.
- 화면에 `E`, `A/B/X/Y`를 하드코딩하지 않고 현재 binding glyph를 표시한다.
- 팝업 중 이동 입력은 소비하지 않고 UI focus를 가둔다.
- 장치 전환은 대상, 팝업, 선택, 자원, 언어를 바꾸지 않는다.
- 자동 테스트와 키보드·마우스 경로는 검증되어 있으나 물리 게임패드 전체 플레이는 `UNVERIFIED`다.

### 13.2 현지화

- `ko`가 기준 원문이고 `en`을 정식 지원한다.
- `qps-long`은 영어를 결정적으로 늘려 레이아웃을 검증하는 QA 전용 로케일이며 언어 목록에 노출하지 않는다.
- 향후 `es`, `ja`, `zh-Hans`, `zh-Hant`는 기존 안정 키, context, intent, placeholder 계약을 재사용한다.
- 언어마다 새 gameplay ID를 만들거나 문자열 비교로 상태를 판정하지 않는다.
- 언어 변경 뒤 현재 화면이 즉시 갱신되며 날짜, 자원, 설비, 수색물, 엔딩 후보는 불변이어야 한다.
- 중국어 간체·번체는 자동 변환본을 그대로 승인하지 않고 별도로 번역·검수한다.
- 코미디는 직역보다 상황 의미와 감정 강도를 보존하되 숫자·자원·원인·결과는 바꾸지 않는다.

## 14. 아트와 오디오 방향

### 14.1 비주얼

- 밝고 따뜻한 열대색의 오리지널 2D 측면 일러스트.
- 해변·맹그로브·숲·절벽·동굴·난파선·폐시설은 같은 섬의 통일감을 유지하면서 실루엣과 전경으로 즉시 구분한다.
- 김씨는 평범하고 약간 지친 생활인으로 읽히며, 과장된 반응과 선명한 포즈로 코미디를 전달한다.
- 캠프는 시작층 위 2층과 아래 지하실이 보이는 측면 절개형으로 표현한다.
- 설비·아이템·위험은 작은 크기에서도 기능 실루엣과 상태가 구분되어야 한다.
- 벌레·야생동물·독초·질병은 고어 대신 동작, 상태 아이콘, 김씨의 코믹 반응으로 전달한다.
- 모든 본문과 수치는 이미지에 굽지 않고 엔진 텍스트로 분리한다.
- 참고 작품의 고유 UI, 건물 배치, 캐릭터, 아이콘을 복제하지 않는다.

현재 뗏목 생성 후보 `escape.raft.shore-launch-a`는 `review-only`다. 사용자가 채택하기 전에는 런타임에 연결하거나 최종 아트로 간주하지 않는다.

### 14.2 오디오

오디오는 게임잼에서 기능 중심의 `PROVISIONAL` 범위다.

- 캠프, 해안, 숲, 동굴의 짧은 환경 루프
- 수색 시작·발견·가방 교체·위험 예고·치료·제작·탈출 단계의 명확한 피드백음
- 허기·부상·질병 경고는 서로 구분하되 반복 피로를 줄인다.
- 엔딩은 3~5컷 전환을 살리는 짧은 테마와 코믹 sting을 사용한다.
- 음성 더빙과 지역별 완전 고유 음악 세트는 게임잼 필수 범위가 아니다.

## 16. 상태·데이터 설계 원칙

### 16.1 안정 ID

지역, 수색물, 발견물, 자원, 도구, 설비, 위험, 탈출법, 행동 통계, 엔딩은 언어와 무관한 안정 ID를 사용한다. 화면 표시명과 저장 데이터가 분리되어야 한다.

### 16.2 원자 거래

다음 규칙은 모든 시스템에 공통이다.

- preview·cancel·무효 선택은 무변경.
- Confirm은 요구조건을 다시 검사한 뒤 비용, 상태, 로그를 한 번에 적용.
- 중복 입력, retry, 언어·입력 장치 전환으로 같은 보상·손실을 재적용하지 않음.
- 탈출 실패와 위험 사건은 선언한 대상·수량만 변경.
- 보호 핵심 부품과 완료 프로젝트 단계는 관련 없는 사건으로 손실되지 않음.

### 16.3 결정론적 run

같은 run seed, 날짜, 월드 상태, stable node ID는 같은 수색물, 지역 전망, 위험, pity 결과를 만든다. 플레이어가 실제로 선택한 결과만 저장하며, 밸런스 수정과 locale 변경이 진행 상태를 다시 굴리지 않는다.

### 16.4 텔레메트리 원칙

게임잼 플레이테스트 로그는 run-local 안정 ID, day, result code, pacing band만 기록한다. 이름, 계정, IP, 자유 입력 문장은 수집하지 않는다.

주요 관찰 이벤트는 첫 지역 preview, 첫 수색물 공개, 발견물 선택, 귀환, 위험 예고·해결·회복, 프로젝트 진척·완료, 행동 정체성 변경, 엔딩 판정이다.

## 17. 게임잼 범위

### 17.1 반드시 포함

- 최소 7개 수색 지역의 지도 노드와 서로 다른 전망·위험·장비 계약
- 환경 수색물, 숨겨진 발견물, 담기·교체·남겨 두기
- run seed·stable node ID 기반 잔여물·고갈·장벽·위험 지속성
- 직접 이동·근접 설비 상호작용과 작은 상황형 팝업
- 캠프파이어·탈출 설비·층 연결부만 고정 지점, 그 외 설비는 완성된 1층·2층·지하실에서 충돌 검사를 거친 자유 배치
- 침대·소파의 시작층·2층·지하실 간 무료 재배치
- 4→6→8→10칸 가방 성장
- 돌도끼 장벽, 수영 수색
- 벌레·야생동물·위험 식물 중 두 종류 이상과 질병 한 종류의 완결 흐름
- 플레이 가능한 뗏목·대형 연기·무전 구조
- 대표 일반·코믹·희귀·장기 체류 엔딩과 3~5컷 표현
- 한국어·영어 의미 동등성과 확장 가능한 키 구조
- 키보드·마우스 전체 경로와 게임패드 공통 액션

### 17.2 제외 또는 연기

- 바닥 개별 줍기를 주 파밍으로 사용
- 수색물 재추첨을 이용한 무한 파밍
- 플레이 가능한 조명탄·고지대 중계소 완성
- 7지역마다 완전히 다른 전투·보스 시스템
- 픽셀 단위 파괴 지형과 물리 기반 건축
- 생태계 번식·이동·자원 재생 시뮬레이션
- 2층·지하 외 추가 다층 구조와 구조 안정성 계산
- 21개 엔딩 전체의 완성 코믹북 아트
- 게임 종료 후 이어하기 세이브
- 사용자 설정 run의 완성 UI·밸런스
- Steamworks 업적·스토어·배포 연동
- 음성 더빙과 지역별 완전 고유 음악 세트

### 17.3 하지 말아야 할 스코프 축소

30분에 맞추기 위해 핵심 경험을 다음처럼 바꾸지 않는다.

- 수색물 대신 바닥 아이템을 자동 줍게 만들기
- 캠프 이동을 없애고 전역 버튼 대시보드로 회귀하기
- 모든 탈출 재료를 한 지역에 모으기
- 위험을 무예고 랜덤 자원 차감으로 단순화하기
- 엔딩을 마지막 버튼 하나만 보고 고르기

### 18.1 핵심 루프

- 첫 사용자가 10분 안에 지도 선택 → 환경 수색물 공개 → 발견물 선별 → 귀환 → 투자까지 완료한다.
- 이미 수색한 날 재출발 시 정확한 원인 안내가 나타난다.
- 남겨 둔 발견물, 고갈 수색물, 장벽, 영구 위험이 재방문에도 유지된다.

### 18.2 캠프

- 상시 대형 캠프 행동 패널이 없다.
- 김씨가 설비에 직접 접근해야 팝업이 열리고, 안내는 대상 하나만 표시한다.
- 작업대와 연결부가 겹칠 때 작업대 사용이 우선되며 지하실 미리보기가 강탈하지 않는다.
- 배치 미리보기는 플레이 공간을 불투명 네모로 덮지 않고 현재 유령과 원인만 표시한다.
- 한 run에서 2층·지하실을 만들고 각 공간에 일반 설비를 배치·사용할 수 있다.
- 창고·증축 계획 지점에서 위층·지하실 연결부를 발견하고 미리볼 수 있다.
- 건설·증축 실패와 연구 성공·실패는 해당 팝업을 유지한 채 결과를 내부에 표시한다.

### 18.3 수색·가방

- 처음 보는 수색물은 정확한 내용물을 숨긴다.
- ko/en, 키보드·게임패드가 같은 발견 결과와 거래를 낸다.
- 발견물 트레이는 공개된 모든 항목과 현재 가방 전체를 동시에 보여 준다.
- 가방 4칸의 담기·교체·남겨 두기와 6·8·10칸 단계 업그레이드가 실제 플레이에서 도달 가능하다.
- 일곱 지역에 정확히 84개 stable 수색물이 있고 일반 자원 432단위가 소·중·대 수율로 분산된다.

### 18.4 위험

- 최소 두 지역 위험과 질병 하나가 예고 → 노출 → 효과 → 완화·치료로 이어진다.
- 한 사건이 같은 자원·설비를 중복 차감하지 않는다.
- 보호 부품과 완료 탈출 단계가 위험으로 소실되지 않는다.

### 18.5 탈출·엔딩

- 뗏목은 선체·돛·보급·날씨 창을 원자적으로 처리하고 재시도 시 진척을 보존한다.
- 뗏목 3/3 상태는 정확한 다음 행동을 표시하며 닫힌 출항 창 확인으로 식량을 차감하지 않는다.
- 모든 탈출 팝업의 보호 핵심 부품은 이름과 `0/1` 또는 `1/1`을 함께 표시한다.
- 무전은 서로 다른 지역의 세 고유 부품 없이는 완료할 수 없다.
- 연기는 보호 부싯돌과 대량 나무를 요구하되 유한 자원 때문에 모든 탈출 경로가 막히지 않는다.
- 25~35분 안에 대표 탈출 엔딩에 도달하는 seed와 페이싱 프로필이 있다.
- 엔딩 화면이 탈출법, 우세 행동, 특별 사건의 근거를 보여 준다.

### 18.6 UI·현지화

- 1280×800 ko/en에서 HUD, 지도, 수색 트레이, 다층 캠프, 질병 상태, 엔딩 근거가 플레이 공간을 과도하게 가리지 않는다.
- qps-long에서 잘림, 겹침, tofu, 입력 glyph 유실, 의미를 숨기는 말줄임표가 없다.
- 색상 외 아이콘·문구로 위험·잠금·유효 상태를 구분한다.

## 19. 현재 구현 상태 스냅샷

기준: 2026-08-28 O8 정확 소스 Release·패키지 자동 검증 완료. O8-H1은 기능 실패 판정 없이 `STOPPED · CONTENT_PRESENTATION_GATE`로 종료했다. 현재 단계는 제출 후보가 아니라 시스템 알파이며, 상세 감사와 다음 제작 게이트는 `Docs/Design/gamejam-content-presentation-production-plan.md`를 따른다.

### 19.1 확인된 기반

- Unity 프로젝트, Windows 개발 빌드, 한국어·영어, 공간형 캠프, 수영, 50일 캠페인 데이터 기반이 존재한다. O8부터 일반 설비는 다층 자유 배치, 탈출 장비·모닥불·연결부는 고정 지점을 사용하는 하이브리드 계약으로 전환한다.
- Wave 19 자동 회귀는 21/21 PASS다.
- Wave 20 뗏목 게이트는 최종 통합 결과 16/16 GREEN으로 기록되어 있다.
- 컴파일 0 error / 0 warning, Windows 개발 빌드, headless smoke, Addressables·방화벽 예방 게이트가 통과한 기록이 있다.
- O6 목표 계약은 7지역·21 아키타입·84개 stable 수색 node·432 일반 자원, 소·중·대 혼합 수율, 질병 전 주기, 위층·지하실, 보호 부품·3/5 pity·3탈출·composite save다. O5의 “기존 node 내용물 일괄 3배” 배치는 폐기하며 O6 통합 게이트와 실제 플레이로 다시 확정한다.
- 엔딩 카탈로그는 21개이며, GAME JAM Day 20 프로필의 `ending.gamejam.stay.natural-kim`과 `ending.gamejam.stay.island-engineer`가 조기 탈출 우선·기존 Day 50 보존 계약과 함께 자동 검증됐다.
- 뗏목·대형 연기·무전은 현재 게임잼 플레이 가능 계약, 조명탄·중계소는 데이터·설계 전용 계약이다.
- 새 게임에서는 세 탈출 설비가 월드에 존재하지 않는다. 창고·증축 계획 지점에서 설비를 건설한 뒤 해당 오브젝트와 아이콘이 생성되며, 경로명·진행도는 상시 월드 텍스트가 아니라 근접 안내와 팝업에서만 표시한다.
- 수집 지도 카드와 상세 패널은 각 지역의 `남은 일반 자원 / 초기 일반 자원`과 정수 백분율을 같은 저장 원장에서 표시한다.
- 캠프 설비·지도·앨범·탈출 설비·수색 node에는 텍스트 없는 공통 상호작용 표식을 사용하고, 고갈 대상은 회색·빗금 상태로 구분한다.

### 19.2 남은 검증·조정

- O7-H1은 정확 소스 `1df5c7de1a82d21ef9c902b98d2761e7d8730368` 후보에서 17분 35초 진행 후 중단됐다. 자동 게이트와 달리 실제 플레이에서는 초반 식량·돌·도끼 선행 관계가 진행을 막았고, 컴팩트 가방·다층 설비 이동·진수대 피드백도 실패했다.
- O7 수색 공간은 7지역·84 stable node를 유지한다. node 상태와 보호 부품 배치는 보존하고, 지역 폭과 간격 분포만 넓혀 대부분의 수색물이 서로 떨어져 보이게 하며 일부 자연스러운 군집만 남긴다.
- O7 자원표는 지역 특화를 배타적 종류 제한으로 만들지 않는다. 난파선·폐중계소에도 환경상 타당한 나무·표류물·돌을 섞고, 전자 부품은 기술 지역에 집중한다.
- 일광은 현장에서 채우는 회복 수치가 아니라 당일 수색 시간 예산이며 다음 날 초기화된다. 기력과 체력은 실제 휴식·식사·치료 상호작용과 같은 문장으로 안내한다.
- O8은 해변만 최초 해금하고 `해변→숲→얕은 바다→바위 해안→동굴→난파선→폐중계소` 첫 진입 순서로 다음 지역을 하나씩 연다. 해변은 도구 없이 식량·나무·표류물을, 숲은 식량·돌을 보장한다.
- 첫 loop 5~10분·대표 탈출 25~35분은 합성 no-cheat profile 28.98분으로 자동 계약을 통과했으나 실제 사용자 측정은 `UNVERIFIED`다.
- 물리 게임패드와 KO 3명·EN 3명 첫 사용자 세션은 `UNVERIFIED`이며 자동화 결과로 대신하지 않는다.
- 최종 50일 비용·드롭·위험 빈도·pity·행동 임계값은 `PROVISIONAL`이다.
- 공식 영문 제목, Steam App ID, 파트너 권한, Steamworks 업적·출시 준비는 `NOT_READY`다.

### 19.3 구현 우선순위

1. **O9 콘텐츠·프레젠테이션 알파**: 시놉시스·도입·아트 style benchmark를 잠그고, 최종 방향 UI, 김씨 core animation, 캠프 1층·해변·숲, 대표 엔딩 1종과 첫 루프 기능 오디오를 실제 런타임에 연결한다.
2. O9 뒤 5~10분 first-loop 사용자 테스트로 설명자 없이 캠프→지도→수색→선별→귀환→첫 투자를 이해하는지 검증한다.
3. **O10 30분 콘텐츠 베타**: 7지역·다층 캠프·19개 필수 아이템·위험·세 탈출 설비, 5 core ending과 필수 오디오를 연결한다.
4. O10 뒤에만 30분 자연 플레이를 재개하고, O8 기능 체크리스트와 세 탈출 경로 완주를 함께 검증한다.
5. **O11/O12**에서 코믹·희귀 변형, 행동 modifier, 물리 게임패드, KO 3명·EN 3명 first-user 세션과 Release 제출 패키지를 완료한다.

## 20. 밸런스 거버넌스

다음 값은 최종 확정하지 않는다.

- 자원 비용과 드롭 수량
- 허기·체력·일광 소모
- 날씨·위험 빈도와 위험 예산
- 탈출 준비 일수와 대형 연기 나무 총량
- 핵심 부품 pity 횟수
- 행동 점수·엔딩 임계값
- 게임잼 장기 체류 판정일

한 검증 빌드에서는 다음 축 하나만 바꾸고, 같은 seed와 대표 경로를 전후 비교한다.

`REGION_ACCESS`, `TRAVEL_TIME`, `RESOURCE_FORECAST`, `HAZARD_PRESSURE`, `RECOVERY_WINDOW`, `ESCAPE_PREPARATION`, `IDENTITY_THRESHOLD`.

조정 우선순위는 **기술 오류 → 원인 이해 실패 → 발견성 실패 → 밸런스 실패**다. UI가 안 보여서 실패한 경우를 자원 지급으로 해결하지 않는다.

## 22. 용어집

| 용어 | 의미 |
|---|---|
| run | 새 게임부터 탈출 또는 장기 체류 엔딩까지의 한 플레이 |
| stable ID | 언어·표시명과 무관하게 저장·판정에 사용하는 고정 식별자 |
| 환경 수색물 / search node | 내용을 모른 채 접근해 뒤지고 발견물을 공개하는 풀숲·바위틈 등의 대상 |
| 발견물 / find | 수색 뒤 공개되어 가방에 담거나 남길 수 있는 자원·부품 |
| 알려진 잔여물 | 한 번 확인했지만 가져가지 않아 해당 수색물에 남은 발견물 |
| 보호 핵심 부품 | 탈출법에 필요한 고유 부품. 일반 도난·피해로 삭제되지 않음 |

| pity | 반복 실패 시 단서·가중치·보장을 제공하는 softlock 예방 장치 |
| modifier panel | core 엔딩 뒤 우세 행동·특별 사건을 추가하는 선택 컷 |
| qps-long | 문자열 팽창과 글리프·레이아웃을 검사하는 비출하 QA 로케일 |

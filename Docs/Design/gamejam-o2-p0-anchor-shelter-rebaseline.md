# GAME JAM O2 P0 및 고정 설치 지점형 쉘터 리베이스

## 판정

후보 `b3f980f`는 O2 사람 테스트에서 `REJECT`다. 가방이 가득 찬 상태로 새 발견물을 담으면 교체할 가방 패널이 숨겨져 진행할 수 없다.

## P0 교정 계약

- pending swap 동안 발견물 tray와 교체용 가방 슬롯을 동시에 표시한다.
- 두 패널은 1280×800 KO/EN에서 겹치지 않는다.
- 활성 가방 슬롯은 키보드·마우스와 게임패드로 선택 가능하다.
- 슬롯 교체는 기존 원자 거래를 보존하고, 취소하면 가방·수색물 상태가 변하지 않는다.
- 자동 검증은 패널 활성, 6개 슬롯의 가시성, 비겹침, 선택 대상의 실제 활성·상호작용 가능 상태까지 검사한다.

## 캠프 리베이스 계약

- 제한적 자유 배치와 임의 좌표 커서를 폐기한다.
- 설비 선택 뒤 현재 방의 호환 가능한 고정 설치 지점만 나타낸다.
- 좌우/포인터로 지점을 선택하고 확인하면 김씨가 접근 가능한 위치에 설치된다.
- 저장 정본은 `StableRoomId + StableAnchorId`다. 기존 좌표 저장은 가장 가까운 호환 지점으로 한 번 마이그레이션한다.
- 시작층은 처음부터 지붕·기둥·실내 바닥을 가진 열대 표류물 쉘터다.
- 2층 완공은 시작층 위에 실내층과 새 지붕을, 지하실 완공은 아래에 굴착된 방과 사다리 연결을 보여 준다.
- 침대와 소파는 제작 비용, 고정 설치 지점, 월드 실루엣, 근접 상호작용, 하루 휴식 효과, 저장·복원을 갖는다.
- 완성 설비의 상호작용 우선순위는 모듈 연결부보다 높다.

## 오리지널 아트 경계

참고작에서는 절개형 다층 거점, 방별 설비 배치, 캐릭터 직접 접근과 사용이라는 기능 원칙만 분석한다. 제3자 고유 UI, 아이콘, 화면 배치, 쉘터 구조와 아트는 복제하지 않는다. 결과물은 밝은 열대색, 표류목·천막·선체 조각으로 만든 《김씨 생존기》 고유 쉘터다.

## 새 후보 게이트

1. O2 P0 가방 교체 재현이 GREEN이다.
2. 자유 좌표 없이 시작층·2층·지하실의 고정 설치 지점에 설비를 배치·재배치한다.
3. 시작층 지붕과 층별 공간이 플레이 화면에서 즉시 구분된다.
4. 침대·소파를 설치하고 직접 접근해 휴식 준비를 할 수 있다.
5. 저장·복원 뒤 방과 설치 지점이 유지된다.
6. compile 0 errors, 기존 수색 원자성·세 탈출·엔딩 회귀가 GREEN이다.
7. KO/EN 1280×800 캡처와 새 Windows 후보의 해시를 기록한다.

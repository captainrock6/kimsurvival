## 검수 해석

Forge 기계 검수는 1672×941 불투명 화면을 `ui_set`의 투명 파츠 규칙으로 검사해 `missing-alpha` 한 건, 70점으로 기록했다. 이 파일은 잘라 쓰는 UI 파츠가 아니라 화면 전체의 밀도·색·간격을 판단하는 불투명 스타일 벤치마크이므로 투명도 실패는 용도/검수 유형 불일치다. 이를 숨기거나 자동 재생성하지 않는다.

시각 검토에서는 다음 조건을 충족했다.

1. 김씨와 주요 설비의 실루엣이 배경보다 강하다.
2. 화면 중앙의 이동·배치 영역이 UI에 가려지지 않는다.
3. 상단 HUD와 좌하단 가방의 점유 면적이 이전 후보보다 작다.
4. 래스터 본문을 최종 UI로 사용하지 않으며 KO/EN은 Unity TMP로 유지한다.

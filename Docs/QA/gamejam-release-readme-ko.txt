《김씨 생존기: 무인도》 GAME JAM Windows 빌드

실행
1. ZIP을 새 폴더에 완전히 풉니다. ZIP 안에서 직접 실행하지 마세요.
2. KimSurvivalIsland.exe, KimSurvivalIsland_Data, UnityPlayer.dll, MonoBleedingEdge가 같은 폴더에 있는지 확인합니다.
3. KimSurvivalIsland.exe를 실행합니다. 기본 언어는 한국어이며 게임 안에서 English로 전환할 수 있습니다.

핵심 플레이
- A/D 또는 방향키로 이동하고, 가까운 대상에서 E 또는 표시된 확인 입력으로 상호작용합니다.
- 베이스캠프의 설비에 직접 다가가 제작·건설·연구·회복을 수행합니다.
- 수색 지도에서 지역의 위험도와 예상 자원을 확인한 뒤 출발합니다.
- 수색지의 풀숲, 바위틈, 잔해 같은 지점을 뒤져 제한된 물자를 선택해 가방에 담고 귀환합니다.
- 뗏목, 대형 연기 신호, 무전 구조 신호 등 서로 다른 탈출 경로를 완성하면 행동 기록에 따른 엔딩을 볼 수 있습니다.
- 기본 생존 기한은 50일이지만 게임잼 빌드의 한 판 목표 시간은 약 25~35분입니다.

패키지 확인
- BUILD-INFO.txt에는 정확한 소스 커밋과 실행 파일·게임 코드 해시가 기록됩니다.
- SHA256SUMS.txt에는 패키지 안 모든 파일의 SHA-256이 기록됩니다.
- QA-CHECKLIST-KO.md에는 동일 후보로 진행할 30분 수기 플레이테스트 절차와 기록표가 있습니다.
- 이 빌드는 네트워크 디버그 연결이 없는 Windows x64 비개발 후보입니다.

문제 보고 시 Windows 버전, 화면 배율, 해상도, 입력 장치, 발생한 Day·지역·대상, 기대 결과와 실제 결과를 함께 기록해 주세요.

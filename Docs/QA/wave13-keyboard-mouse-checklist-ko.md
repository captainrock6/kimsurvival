- [ ] 압축 해제 후 네 필수 구성요소(EXE, Data, UnityPlayer.dll, MonoBleedingEdge)가 모두 있다.
- [ ] 한국어가 기본이고 1280×800에서 상단 HUD·내레이션·근접 안내·하단 도움말이 잘리지 않는다.

## 조작 경로

- [ ] `A/D` 또는 좌우 화살표로 이동하고 `W`/위 화살표/`Space`로 점프한다.
- [ ] 설비와 직접 연결 슬롯에서 `E` 또는 `F`로 상호작용한다.
- [ ] `Enter` 또는 UI 왼쪽 클릭으로 확인하고 `Esc`로 취소·복귀한다.
- [ ] 배치/preview에서 마우스 이동, 왼쪽 클릭 확인, 오른쪽 클릭 또는 `Esc` 취소가 동작한다.
- [ ] 가방 교체가 필요할 때 숫자 `1`~`6`과 UI 클릭이 활성 슬롯 규칙을 지킨다.
- [ ] 멀리서는 근접 안내 0개, 가까이서는 단일 대상 안내 1개, 팝업 중 안내 숨김, 취소 뒤 같은 대상 안내 복귀가 유지된다.

Kim's Survival Story: Desert Island — GAME JAM Windows Build

Launch
1. Extract the ZIP into a new folder. Do not run the game from inside the ZIP.
2. Keep KimSurvivalIsland.exe, KimSurvivalIsland_Data, UnityPlayer.dll, and MonoBleedingEdge in the same folder.
3. Run KimSurvivalIsland.exe. Korean is the default language; English can be selected in game.

Core play
- Move with A/D or the arrow keys and use E or the displayed confirm input near an interactable object.
- Walk up to camp facilities to craft, build, research, or recover.
- Use the search map to compare regional danger and expected resources before departing.
- Search bushes, rock gaps, and wreckage, choose from their finite discoveries, pack what fits, and return to camp.
- Complete different escape routes such as the raft, large smoke signal, or radio rescue signal. The ending reflects what Kim did during the run.
- The default survival deadline is 50 days; the game-jam run is paced for an ending in about 25–35 minutes.

Package identity
- BUILD-INFO.txt records the exact source commit and hashes for the executable and managed game assembly.
- SHA256SUMS.txt records SHA-256 for every other file in the package.
- QA-CHECKLIST-KO.md contains the 30-minute manual playtest procedure and result ledger for this exact candidate.
- This is a non-development Windows x64 candidate without the Unity player connection debugger.

When reporting an issue, include the Windows version, display scaling, resolution, input device, Day/region/object, and expected versus observed behavior.

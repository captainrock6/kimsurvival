## 장치·프롬프트

- [ ] 장치를 연결한 뒤 게임이 입력을 인식하며 키보드 조작 뒤 패드 조작 시 glyph가 장치에 맞게 바뀐다.
- [ ] ko/en 전환과 장치 전환이 서로의 locale·Day·자원·대상 latch를 바꾸지 않는다.
- [ ] 현재 코드 경로의 기대 의미: 왼쪽 스틱/방향키 이동, A 점프·확인, X 상호작용, B 취소·귀환, Y 언어 전환. 실제 장치 표기가 다르면 그대로 기록한다.

## 전체 조작

- [ ] 캠프 이동과 네 설비의 단일 근접 대상 선택이 안정적이다.
- [ ] 설비 팝업을 열고 방향 입력으로 항목 이동, A 확인, B 취소 후 동일 대상 복귀가 된다.
- [ ] 직접 연결 슬롯 세 곳에서 첫 후보, 세 후보 순환, preview, cancel, 확정을 완료한다.
- [ ] 제한적 자유 배치에서 이동·확인·취소·무료 재배치를 마우스 없이 완료한다.
- [ ] 수색·점프·입수·수영·연안 채집·육지 복귀를 완료한다.
- [ ] 가방 4/6 슬롯 교체와 신호 1·2단계를 완료한다.
- [ ] ko와 en 각각 1280×800 핵심 루프에서 프롬프트 의미가 동일하고 잘림이 없다.

수동 판정: PASS / FAIL / UNVERIFIED
